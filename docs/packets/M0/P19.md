# P19 — `ImageSpec` + transform rules (resize / crop / undistort)

Spec: spec 7.2, spec 3.1, Appendix B.2, `INV-14`, spec 28.2 Wave 3. Review class C.
Design note (written first): `docs/design/image-spec.md`.

```
crates/es-ir/src/image.rs

```

## spec

- `ImageSpec` with every field of spec 7.2: `width`, `height`, `channels`, `dtype`,
  `color_space`, `camera_model`, `intrinsics`, `extrinsics` (`es_math::conventions::Pose`,
  `T_body_camera`), `distortion`, `shutter`, `exposure`, `rate_hz`, `depth_scale`.
- `Intrinsics { fx, fy, cx, cy, skew }` with `scaled(sx, sy)`.
- `resized(w, h, rescale)`, `cropped(rect, rescale)`, `undistorted(new_intr)` exactly as
  Appendix B.2.
- `intrinsics_consistent_with(&other)` — the comparison behind `OBS-034`. Emitting the
  diagnostic is the caller's (compiler's) job; this crate supplies the predicate and the code.

## oracle

```
cargo test -p es-ir --lib -- image::
```

## acceptance

- `resized(320, 240, true)` on a 640×480 spec halves `fx, fy, cx, cy`.
- `cropped(Rect { x: 80, y: 60, .. }, true)` shifts `cx` by −80 and `cy` by −60 and leaves
  `fx, fy` alone.
- `rescale = false` leaves the intrinsics bit-identical, and the result is **not**
  `intrinsics_consistent_with` the original (this is what `OBS-034` reports).
- `undistorted` clears `distortion` to `None` and installs the new intrinsics.
- serde round-trip of an `ImageSpec` is equality-preserving.

## forbidden

Any file outside `context`. Resampling or any pixel work (that is `es-render` / the compiler).
Observation IR node schemas (P21). Emitting `OBS-021` / `OBS-034` (P26 / compiler). Skipping
the intrinsics transform on a geometry change (`INV-14`). Defaulting `rescale` to `false`.
