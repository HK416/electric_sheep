# P13 — ECS (아키타입, SoA)

Spec: §4.2 (레이어 1 `es-core`), §3.4 (결정성), §28.2 Wave 2. 검토 등급 B.

## context (범위)

```
crates/es-core/src/ecs.rs
crates/es-core/src/lib.rs
docs/packets/M0/P13.md
```

## spec (사양)

아키타입 기반 SoA 저장소이며, 설계상 최소한이다.

- `Entity` — `{ index: u32, generation: u32 }`, `Copy + Ord`; 오래된(stale)
  핸들은 결코 해석되지 않는다.
- `Component` — `'static + Send + Sync`에 대한 포괄 마커다.
- `World` — `spawn`, `despawn`, `insert`, `get`, `get_mut`, `query::<Q>()`.
- `query::<(&A, &mut B)>()`는 쿼리의 모든 컴포넌트 타입을 가진 모든
  아키타입에 대해 `(Entity, Q::Item)`을 산출한다.
- 반복 순서는 결정적이다: 아키타입은 생성 순서, 행은 엔티티가 해당
  아키타입에 들어온 순서를 따른다(`despawn`은 swap-remove를 하여 행을
  뒤바꾸지만, 여전히 연산 시퀀스에 대한 순수 함수다).
- `BTreeMap` / `Vec`만 사용한다; `HashMap`은 `clippy.toml`에서
  거부된다(spec 3.4).
- 변경 감지 없음, 이벤트 없음, 스케줄 없음, 시스템 없음, 컴포넌트 제거 없음.

`unsafe`는 쿼리 이터레이터의 컬럼 포인터 취득에 국한된다; 모든 지점에
`// SAFETY:` 주석을 단다. 한 쿼리 안에 중복된 컴포넌트 타입이 있으면
패닉한다(에일리어싱).

## oracle (오라클)

```
cargo test -p es-core --lib ecs::
```

## acceptance (수용 기준)

- 왕복: `spawn` -> `insert` -> `get` / `get_mut` -> `despawn`; 오래된
  `Entity`는 `None`을 준다.
- 아키타입 이전(migration)은 이전에 삽입된 컴포넌트 값을 보존한다.
- Proptest: 동일한 연산 시퀀스를 두 개의 `World`에 재생하면 동일한 쿼리
  반복 순서를 낳는다(순서는 연산 시퀀스에 대한 순수 함수다).
- `cargo clippy -p es-core --all-targets -- -D warnings`가 깨끗하다.

## forbidden (금지)

`context` 밖의 어떤 파일도 안 된다. 시스템 / 스케줄 / 이벤트 / 변경 감지 금지.
`HashMap` 금지. 병렬 쿼리 금지(스레딩은 P14의 소관). `es-math`에 대한 의존
금지.
