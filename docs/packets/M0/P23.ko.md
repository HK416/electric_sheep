# P23 — Deployment IR + `SafetyEnvelope` 스키마

Spec: spec 9 (전체), spec 5.1, spec 8.5, Appendix B.4, `INV-12`. 리뷰 클래스 A(safety).

## context (범위)

```
crates/es-ir/src/deployment.rs
crates/es-ir/tests/            (none needed; the oracle is the module's own test mod)
docs/packets/M0/P23.md
```

## spec (사양)

- `DeploymentIr { schema_version, robot, action, safety, execution, deadlines, watchdogs,
  fallback, rate }` — spec 9.2가 나열하는 모든 필드. `action`은 spec 8.5 `ActionSpec`
  (space, dim, horizon, execute_chunk)의 배포 측 축약형이다; 저작 형식은 Learning IR
  소관이다.
- `SafetyEnvelope`(spec 9.3): 관절별 `position` + `position_soft_margin`, `velocity_max`,
  `acceleration_max`, `torque_max`, 선택적 `jerk_max`, `action_rate`(틱당 1차·2차 차분),
  `workspace`(box / cylinder / convex hull), `ee_velocity_max`, `min_self_distance`,
  `min_env_distance`, `contact_force_max`. `Vec`는 `n_joints()`로 크기가 정해진다; Appendix
  B.4의 const-generic `SafetyEnvelope<NJ>`는 `es-safety` 런타임 미러이며 이 타입이 아니다.
- `Watchdog` / `WatchdogSet` / `FallbackPolicy`는 `NanInf` watchdog을 제외하면 spec 9.4
  그대로이다: 비유한(non-finite) 값 거부는 `SafetyEnvelope::contains`에서 무조건 실행되므로
  설정으로 끌 수 없다(`INV-12`).
- 지속시간은 `Micros(u64)`이다; 비율은 `es_core::time::TickRate`이다. `f64` 시간은
  사용하지 않는다(spec 3.4).
- `DeploymentIr::validate(&self) -> Vec<Diagnostic>`와 `CanonWriter` 기반의
  `deployment_hash()`(모든 필드, `f64`는 정규화됨).

cargo fmt -p es-ir --check

## acceptance (수용 기준)

- 7-DoF fixture는 진단 0건으로 검증을 통과한다; serde 라운드트립은 동등성을 보존한다.
- 역전된 position 한계는 `DEP-012`를 보고한다; 0 또는 `NaN` 한계는 `DEP-013` /
  `DEP-011`을 보고한다; 관절 수 불일치는 `DEP-010`을 보고한다.
- 충족할 수 없는 데드라인은 `DEP-021`을 보고하며, 이로 인해 데드라인을 초과하게 된
  watchdog은 `DEP-022`를 보고한다; 중복된 watchdog은 `DEP-024`를 보고한다; 한계를
  벗어난 retract 궤적이나 빈 controller id는 `DEP-030`을 보고한다.
- `deployment_hash`는 호출 간 안정적이며, 한계·workspace·실행 모드 중 어느 것이
  바뀌어도 변한다.
- `testing::arbitrary_deployment_ir()`(proptest, `cfg(test)` — `proptest`는
  dev-dependency이며 P23은 `Cargo.toml`을 소관하지 않는다)는 항상 깨끗하게 검증되고
  항상 해시된다.
- 어떤 필드·플래그·변형으로도 envelope를 비활성화할 수 없다; `contains` 검사는
  한계를 넓히는 방식으로만 대응한다.

## forbidden (금지)

`context` 밖의 모든 파일 — 특히 `lib.rs`, `codes.rs`, `graph.rs`, `types.rs`,
`hash.rs`, `Cargo.toml`와 나머지 IR 모듈들. 어떤 런타임 동작이든: clamping, projection,
filtering, counters, `SafetyPlane` 자체(`es-safety`, 레이어 8). 어떤 policy, tensor,
runtime 타입이든(그것은 `es-safety`가 `es-policy`에 도달하게 만든다, spec 4.2 rule 8).
`DEP-031`(envelope가 로봇 성능을 초과함) — 로봇 기술(description)이 필요하므로 cross-IR
패스(P26) 소관이다. `DEP-114`(런타임 지원) — 컴파일러, spec 11.6. 새 `DEP-` 코드는
사전(dictionary) 병합 전까지 `TODO(P27-merge)`가 붙은 로컬 `pub const`로 존재한다.
