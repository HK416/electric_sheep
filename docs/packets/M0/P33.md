# P33 — MJCF actuators, sensors, tendons

Spec: spec 18.2 (actuators), spec 18.3 (sensors and realism), spec 17.2 (backend semantic

## spec

- `<actuator>`: `motor`, `position` (`kp`, `kv`), `velocity` (`kv`), `general` (`gainprm` /
  `biasprm`, affine head only). Common attributes `gear` (up to 6), `ctrlrange` /
  `ctrllimited`, `forcerange` / `forcelimited`, resolved through the same `autolimits` rule as
  joint limits. Targets: `joint`, `tendon`, `site`. A `general` actuator whose `dyntype`,
  `gaintype` or `biastype` is not the default produces a warning naming spec 17.2 — the
  backend owns that mapping. Actuator element types outside the four are warned and skipped.
- `<sensor>`: `jointpos`, `jointvel`, `actuatorfrc`, `framepos`, `framequat` (`objtype` +
  `objname` over body / xbody / site / geom / camera), `accelerometer`, `gyro`, `force`,
  `torque`, `touch`, `rangefinder`, `camprojection`. Each carries `noise` and `cutoff`.
- `<tendon>`: `fixed` with `<joint joint coef>` children, `spatial` with `<site site>`
  children, plus `range` / `limited`, `stiffness`, `damping`.
- `<asset>`: `mesh`, `texture`, `material`, `hfield` become `AssetRef`s — path (prefixed with
  `meshdir` / `texturedir`) plus the hash of that path string. No file is opened. An unnamed
  `mesh` takes the file stem. `<geom type="mesh" mesh="...">` and `material="..."` resolve
  through the asset name tables.
- Every name reference resolves through `lookup`, which reports an unresolved name as
  `MjcfError::UnknownRef` with the referencing element's line. An unnamed actuator or sensor
  is named `<element>_<target name>`, so its id stays independent of element order.
- Parse order inside `<mujoco>` is fixed (`compiler`, `option`, `asset`, `default`,
  `worldbody`, `tendon`, `actuator`, `sensor`) regardless of document order, because each
  section resolves names defined by an earlier one.

## acceptance

- `actuated.xml`: four actuators with the right kinds, gains, gear and limits; the `general`
  actuator targets a tendon by name; the fixed tendon keeps its joint coefficients in order
  and the spatial tendon its sites; eleven sensors with the right kinds and targets; an
  unnamed `jointpos` is named `jointpos_hinge1`; `fovy` is stored in radians.
- `assets.xml`: five `AssetRef`s, `meshdir` / `texturedir` prefixes applied, an unnamed mesh
  named from its file stem, a mesh geom and a material resolved to asset ids, a
  `contype=0 conaffinity=0` geom marked `visual_only`.
- An actuator naming a joint that does not exist fails with `UnknownRef` and the right line.
- `<equality>` / `<keyframe>` and any unmapped actuator or sensor element appear in
  `warnings`.

## forbidden

Any file outside `context`. `crates/es-ir/**`. Opening or hashing a referenced asset file
(P31 / P35). Modelling actuator dynamics, noise or transduction — spec 18.2 / spec 18.3
realism belongs to the backend and the observation pipeline; this packet only records the
declared parameters. Adding a trait (`INV-17`). `HashMap` / `HashSet` (spec 3.4).
