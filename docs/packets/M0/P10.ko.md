# P10 — 규약 타입 + serde 왕복 하네스

Spec: §3.1 (좌표계·단위 규약).

## context (범위)

```
crates/es-math/src/conventions.rs
crates/es-math/src/lib.rs
docs/packets/M0/P10.md
```

## spec (사양)

§3.1 표를 타입으로 표현하여, 규약 위반이 조용한 좌표계 불일치가 아니라 컴파일
오류나 테스트 오류가 되도록 한다:

| §3.1 행 | 타입 |
|---|---|
| 오른손 좌표계, Z-업, X-전방 | `Vec3`에 대한 `axis::UP`, `axis::FORWARD`, `axis::LEFT` |
| m / rad / kg / s | `units` 모듈: SI가 저장 단위이며, `DEG_TO_RAD` / `RAD_TO_DEG`만이 유일한 변환이고 I/O 경계에서 적용된다 |
| 쿼터니언 xyzw, 단위 노름, w ≥ 0 | `Quat { x, y, z, w }`, `normalize`는 w ≥ 0으로 정규 형태화한다 |
| 관성: 바디 프레임 대칭 3×3, 주축 분해 캐시 | `Inertia` — 유일한 6개 성분에 캐시된 주모멘트와 주축 회전을 더한 것 |
| — | `Pose { position, orientation }` |

- `f64` 저장이다. `Scalar` 제네릭은 공짜인 곳에서만 쓰는데, 여기서는 공짜가
  아니므로(serde 바운드, 단형화된 상수) 구체 타입으로 둔다. 물리 백엔드는 커널
  경계에서 자신만의 스칼라를 고른다.
- 이들 모두에 `serde` `Serialize`/`Deserialize`가 있으며, 필드명 기반이고
  안정적이다.
- 이것은 선형대수 라이브러리가 *아니다*: `Vec3`는 add/sub/neg/scale/dot/
  cross/norm/normalize를 가지고, `Quat`은 `Mul`/conjugate/rotate/normalize를
  가지며, 호출자가 필요로 하기 전까지는 그 이상 없다.
- 주축 캐시는 `Inertia::new`에서 고정 스윕 횟수의 순환 Jacobi 회전으로(결정적:
  수렴 여부에 따라 반복 횟수가 달라지지 않음) 한 번 계산되어 저장된다.

## oracle (오라클)

```
cargo test -p es-math conventions::
```

## acceptance (수용 기준)

- proptest: `Quat::normalize`는 항상 `w ≥ 0`이고 `|q| == 1`을 `8·f64::EPSILON`
  이내로 만족하며, 성분당 2 ULP 이내로 고정점이다. 이는 비트 단위로 **멱등하지
  않다** — 이미 정규화된 쿼터니언의 `norm()`은 반올림상 1.0일 뿐이므로, 두
  번째 나눗셈이 마지막 비트를 움직인다. 회전을 해싱하는 모든 코드는 한 번
  정규화한 뒤 그것을 해싱해야 한다. (`proptest-regressions/conventions.txt`가
  이를 발견한 시드를 보관한다.)
- proptest: `q`와 `-q`는 동일한 쿼터니언으로 정규화된다(정규 형태화의 취지가
  바로 이것이다).
- `Vec3`, `Quat`, `Pose`, `Inertia`에 대해 JSON을 통한 serde 왕복은 비트
  단위로 동일하다.
- `Inertia`: `R · diag(principal) · Rᵀ`를 재구성하면 원래 성분을 `1e-9`
  이내로 복원한다; 주모멘트는 내림차순으로 정렬된다.
- 축 상수는 §3.1과 일치한다(`UP == +Z`, `FORWARD == +X`, 오른손 좌표계:
  `FORWARD × LEFT == UP`).

## forbidden (금지)

- 행렬 타입 없음, `Mat3`/`Mat4` 없음, 변환 계층 없음, 카메라/이미지 타입
  없음(`ImageSpec`은 §7, `es-ir`의 몫이다).
- 오일러 각 변환 없음(아직 아무도 규약 인자를 명시하지 않았다).
- `from_axis_angle`이나 `sin`/`cos`를 필요로 하는 그 어떤 생성자도 없다:
  `es_math::approx`는 `f32` 전용이고, 레이어 0에서 호스트 `f64::sin`은 플랫폼
  의존적이다(§3.4). 호출자가 생기면, 명시적인 정밀도 계약과 함께 추가한다.
- `serde_json`은 `float_roundtrip` 기능을 켜야 한다. 그렇지 않으면 왕복이
  비트 단위로 정확하지 않다(기본 부동소수점 파서는 1 ULP 어긋날 수 있다).
- `nalgebra`, `glam`, 그 외 어떤 선형대수 의존성도 없다.
- `scalar.rs`, `approx/`, `reduce.rs`, `simd.rs`는 건드리지 않는다.
