## spec

- `pub type F64xN = wide::f64x4;` with `pub const LANES: usize = 4`, so callers write the
  lane count once.
- `dot(a, b) -> f64` and `axpy(alpha, x, y)` over `&[f64]`.
- **Determinism is the contract, not throughput.** `dot` keeps `LANES` independent lane
  accumulators, processes full chunks in order, adds the tail to lane 0.. in order, then
  reduces the lanes in a fixed sequence `l0 + l1 + l2 + l3`. The scalar reference in the test
  performs the identical association, so the two agree bit-for-bit.
- `simd_level() -> SimdLevel` is the runtime dispatch helper: a `std::arch`
  feature-detection stub reporting `Sse2`/`Avx`/`Avx2`/`Neon`/`Scalar`. It is **reporting
  only** — it feeds `hardware_capability` in the §5.3 execution hash. There are no
  per-level function clones, because `wide`'s add/mul are plain IEEE operations with no
  contraction, so an AVX2 clone would produce the same bits as the SSE2 one and buy nothing
  the determinism contract cares about. `multiversion` is deliberately not a dependency:
  it would add a proc-macro and `unsafe` expansion (`#![forbid(unsafe_code)]`) for a
  performance win nobody has measured yet. Revisit when a benchmark shows the gap.

## oracle

```
cargo test -p es-math simd::
```

## acceptance

- proptest, random `f64` slices of length 0–512: `dot` equals the scalar reference
  **bitwise** (`to_bits()` equality), including every tail length `n % LANES`.
- proptest: `axpy` equals the scalar reference bitwise.
- `dot` of an empty slice is `0.0`; length mismatch panics.
- `simd_level()` returns a value and does not panic on the CI host.
- No `unsafe` anywhere in the crate (`#![forbid(unsafe_code)]` at the crate root).

## forbidden

- No `multiversion`, no `std::arch` intrinsics, no `#[target_feature]`, no `unsafe`.
- No FMA (`mul_add`) in `dot`/`axpy` — it would change the result relative to the scalar
  reference and hide contraction (§3.4).
- No rayon / threading: cross-thread reduction is `BinnedAcc`'s job (P11), not this one's.
- Do not touch `scalar.rs`, `approx/`, `conventions.rs`, `reduce.rs`.
