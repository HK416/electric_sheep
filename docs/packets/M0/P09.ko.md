# P09 — `approx`의 Slang 미러 + 계수 동등성

Spec: §3.2 ("Rust와 Slang이 계수·연산 순서를 공유한다"), §3.4, §2.2 (Slang →
SPIR-V).

## context (범위)

```
crates/es-math/slang/approx.slang
crates/es-math/src/approx/slang_mirror.rs
docs/packets/M0/P09.md
```

## spec (사양)

`slang/approx.slang`은 `src/approx/`를 한 줄 한 줄 그대로 미러링한다: 같은
범위 축소, 같은 순서의 같은 Horner 식, 그리고 **같은 십진 리터럴에 묶인 같은
상수 이름**.

- 모든 상수는 (Rust의) `pub const NAME: f32 = <literal>;`에 대응하여 (Slang에서)
  `static const float NAME = <literal>;`로 선언된다. 이름과 리터럴 텍스트는
  정확히 일치해야 한다.
- `slang_mirror.rs`는 테스트만 담는다: 양쪽 파일을 파싱하여 `(NAME, literal)`
  쌍을 추출하고, 두 집합이 바이트 단위로 동일함을(같은 이름, 같은 순서, 같은
  리터럴 텍스트) 단언한다.
- 셰이더는 컴파일될 때 이 식들에 `NoContraction`을 붙여야 한다(§3.4 단계 3);
  이는 컴파일 파이프라인(M2)의 몫이며, 여기서는 미러의 전제조건으로 기록해
  둔다.

## oracle (오라클)

```
cargo test -p es-math slang_mirror
```

## acceptance (수용 기준)

- 한쪽에서만 계수가 추가, 삭제, 이름 변경, 순서 변경, 재포맷되면 테스트가
  실패한다.
- `slang/approx.slang`은 `slangc`에서 컴파일된다 — **Target / Status: 미검증**:
  `slangc`는 아직 CI 호스트에서 사용할 수 없으며, M2에서 셰이더 빌드 캐시와
  함께 연결된다.
- Rust 경로와 GPU 경로 사이의 비트 동일 결과 — **Target / Status: 미검증**:
  §3.4 실행 모드를 가진 Vulkan 디바이스가 필요하며, 이는 P09가 아니라 M2의
  수용 기준이다.

## forbidden (금지)

- 이 패킷에는 Slang 빌드 단계, `slangc` 호출, SPIR-V 산출물이 없다.
- 계수 값 자체는 변경하지 않는다(그것은 P08의 오라클이다).
- 셰이더 크레이트, 빌드 스크립트, `build.rs`를 추가하지 않는다.
