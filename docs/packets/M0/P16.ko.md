# P16 — 실패 시맨틱 타입

Spec: §18.5 (`EnvHealth = Ok | Diverged | Poisoned | Quarantined`,
격리된(quarantined) 환경은 환원에서 제외되며, 격리율 임계값은 5%이고, Safety
Plane 폴백은 실패가 *아니다*), §28.2 Wave 2. 검토 등급 A.

## context (범위)

```
crates/es-core/src/failure.rs
crates/es-core/src/lib.rs
docs/packets/M0/P16.md
```

## spec (사양)

- `EnvHealth` — `Ok | Diverged | Poisoned | Quarantined`;
  `participates_in_reduction()`은 `Quarantined`에서만 false다(§18.5: 격리된
  환경을 마스킹해도 결정성이 깨져서는 안 된다).
- `FailureKind` — `NanDetected`, `Diverged`, `DeadlineMiss`, `SensorDrop`,
  `ActuatorFault`, `ChunkUnderrun`, `SafetyViolation`, `BackendUnsupported`.
- `FailureAction` — `Record | Fallback | Quarantine | AbortEpisode |
  AbortRun`.
- `FailureKind::default_action()` — 전역(total) 함수이며, 종류당 정확히
  하나의 액션을 갖는다.
- `FailurePolicy` — `BTreeMap` 오버라이드에 `quarantine_rate_limit`(기본값
  0.05)을 더한 것; `action_for(kind)`는 오버라이드를 먼저 해석하고 그다음
  기본값을 해석한다.
- `Error`(`thiserror`) — 크레이트 오류 타입: `InvalidTickRate`,
  `InvalidStableId`, `Failure { kind, detail }`.

Safety Plane 폴백은 환경을 `Ok`로 남겨두고 이벤트를 기록한다(§18.5). 따라서
`SafetyViolation`의 기본 액션은 `Fallback`이며 결코 `Quarantine`이 아니다.

## oracle (오라클)

```
cargo test -p es-core --lib failure::
```

## acceptance (수용 기준)

- 모든 `FailureKind`, `FailureAction`, `EnvHealth`, `FailurePolicy`에 대한
  serde 왕복.
- `FailureKind::ALL`은 전수적(exhaustive)이며(`default_action`의 `match`가
  컴파일 타임에 이를 검사한다), 모든 종류는 정확히 하나의 기본 액션에
  대응한다.
- 모든 종류에 대해 `FailurePolicy::default().action_for(k) ==
  k.default_action()`이다; 오버라이드가 우선한다.

## forbidden (금지)

`context` 밖의 어떤 파일도 안 된다. 실패가 Safety Plane을 비활성화하도록
하는 어떤 것도 안 된다(INV-12) — `FailureAction`에는 `Disable` / `Bypass`
variant가 없으며 앞으로도 없을 것이다.
