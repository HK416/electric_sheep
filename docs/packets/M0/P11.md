## spec

Appendix B.8 pins the signature; do not change it:

```rust
pub trait DeterministicAcc<T>: Default + Clone {
    fn add(&mut self, v: T);
    fn merge(&mut self, other: &Self);   // associative + commutative
    fn finish(&self) -> T;
}
pub struct BinnedAcc<const K: usize = 3> { bins: [f64; K], index: Option<i32> }
```

`DeterministicAcc` is one of the seven allowed extension points (INV-17).

Binned/RFA accumulation with `W = 20` bits per bin: every deposit is split by **truncation**
into `K` slices on a global exponent grid and added exactly; rescaling to a coarser index is
an exact bin shift. See the design doc for the exactness argument and the `2^33`-term
ceiling. `finish` sums the bins in a fixed order.

`KahanAcc` is **not** part of this packet and must not be added: compensated summation is
order-dependent and fails the §18.4 invariant.

## acceptance

- proptest, random `f64` vectors (mixed magnitudes, 1–256 elements): `finish()` is
  **bit-identical** for the sequential order, for an arbitrary permutation, and for an
  arbitrary split-merge tree over the same elements.
- proptest: `merge` is commutative (`a.merge(b) == b.merge(a)`, bitwise) and associative.
- `BinnedAcc::default().finish() == 0.0`; a single `add(x)` of a finite `x` whose exponent
  range fits one accumulator returns `x` exactly.
- Accuracy sanity: for vectors within a `2^60` dynamic range the result matches an
  `f64`-pairwise sum to within `1e-9` relative.

## forbidden

- No `KahanAcc`, no Neumaier, no compensated-summation variant.
- No atomic float accumulation, no `HashMap`, no global RNG (proptest seeds only).
- Do not change the `BinnedAcc` field layout or the `DeterministicAcc` method set.
- Do not touch `scalar.rs`, `approx/`, `conventions.rs`, `simd.rs`.
