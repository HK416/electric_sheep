# P05 — API 다이제스트 (ash/Slang/torch/LeRobot 스키마)

Spec: §1.6 (저장소 구조 — `docs/api-notes/`), §1.7 (실패 모드 표: "환각 API" →
`docs/api-notes/` 자동 생성, 버전 고정).

## context (범위)

```
docs/api-notes/README.md
docs/packets/M0/P05.md
```

## spec (사양)

에이전트의 학습 데이터가 오래된 외부 API — `ash`(Vulkan 바인딩), Slang,
`torch`/`tch`의 C++ 표면, LeRobot 데이터셋/체크포인트 스키마 — 는 각각
`docs/api-notes/` 아래에 버전을 고정한 다이제스트 파일 하나씩을 갖는다. 구현
패킷은 이렇게 해서 환각이거나 버전이 어긋난 시그니처 대신 저장소에 커밋된
시그니처를 인용할 수 있다. 이 패킷은 인덱스만 스텁으로 만든다:
`docs/api-notes/README.md`는 관례를 명시한다(라이브러리당 파일 하나, 파일명이나
첫 표제에 고정 버전 명시, 신뢰하기 전에 `cargo check`/실제 설치된 버전과 대조
검증) — 아직 라이브러리 내용은 담지 않는다. 다이제스트 자체는 별도의 후속
패킷들이 담당한다(각각은 그 라이브러리가 실제로 도입될 때 게이팅된다).

## oracle (오라클)

```
test -f docs/api-notes/README.md
```

## acceptance (수용 기준)

- `docs/api-notes/README.md`가 존재하며 다음을 설명한다: 여기에 무엇이 들어가는지,
  라이브러리당 파일 하나, 정확한 버전 고정, 그리고 코드가 그 라이브러리의 API를
  사용한다고 주장하기 전에(이후가 아니라) 다이제스트가 작성되거나 갱신되어야 한다는
  것.
- 이 패킷은 라이브러리별 다이제스트 파일을 추가하지 않는다 — 어떤 패킷이 실제로
  `ash`/Slang/`torch`/LeRobot 시그니처를 필요로 하기 전까지는 범위 밖이다.

## forbidden (금지)

- 조작된 API 시그니처는 없다 — 이 패킷은 관례에 대한 서술이지, 특정 라이브러리에
  대한 내용이 아니다.
- `crates/**`나 `xtask/**` 아래는 수정하지 않는다.
