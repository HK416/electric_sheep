## spec (사양)

- `ElemType`, `Shape`(샘플당 차원만 — 배치 축은 도메인의 소관이다, spec
  5.2), `Unit`, `UnitPowers`, `Frame`, `Align`, `TimeRef`, `PortType`을
  Appendix B.1 그대로 구현한다.
- `m^a · kg^b · s^c · rad^d`에 대한 단위 대수: `mul`, `div`(이름 있는 단위 →
  지수 → 이름 있는 단위), `checked_add`(enum 동등성 요구). 불투명(opaque)
  단위는 `mul` / `div`를 `TYPE-010`으로 거부한다.
- `PortType::compatible` — elem / shape / unit / frame / time / image,
  클래스별로 하나의 진단.
- `PortType::is_policy_input` — `Normalized | Dimensionless | Token`만
  해당한다(`TYPE-011`).
- `TimeRef::join` — 결합 규칙; 정렬이 명시되지 않으면 `TYPE-014`다.
- `PortType::canonical(&mut CanonWriter)`로 노드 파라미터가 재현 가능하게
  타입 해시를 갖도록 한다.
- 다섯 IR이 공유하는 그래프 골격: `NodeId`, `PortRef`, `Edge`, `Graph<N>`,
  `IrNode`, `topo_order`(순환 → `GRAPH-001`), `validate_ports`.
- `CanonWriter` + `canonical_hash`(노드 ID와 노드 순서에 무관) +
  `execution_hash`와 `diff`를 가진 `HashChain`(Appendix B.6).

## acceptance (수용 기준)

- 모든 차원 단위에 대해 `Length / Time == Velocity`, `Velocity * Time ==
  Length`, `mul`은 교환적이고, `div(mul(a,b),b) == a`다; `Quaternion *
  Length`는 `TYPE-010`이다.
- `checked_add(Depth, Length)`는 둘 다 미터 단위임에도 실패한다.
- `PortType::compatible`은 서로 다른 `TimeRef`에 대해 `TYPE-014`를,
  `Policy`에 걸쳐서는 `Ok`를 반환한다.
- `topo_order`는 순환에 대해 `GRAPH-001`을 낳는다; DAG에 대해서는 유효한
  순서다.
- proptest `hash_independent_of_node_ids`와
  `param_change_changes_hash`(Appendix B.7)가 통과한다.
