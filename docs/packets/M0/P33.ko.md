# P33 — MJCF 액추에이터, 센서, 텐던(tendon)

Spec: spec 18.2(액추에이터), spec 18.3(센서와 리얼리즘), spec 17.2(백엔드 시맨틱 매핑 —
매핑되지 않은 transduction은 parse 오류가 아니라 백엔드가 보고할 사항이다), spec 5.3.
Spec 28.2 Wave 4. 리뷰 등급 A. P30과 P32를 기반으로 한다.

## spec (사양)

- `<actuator>`: `motor`, `position`(`kp`, `kv`), `velocity`(`kv`), `general`(`gainprm` /
  `biasprm`, affine head만). 공통 속성 `gear`(최대 6개), `ctrlrange` / `ctrllimited`,
  `forcerange` / `forcelimited`는 joint limit과 동일한 `autolimits` 규칙으로 해석된다.
  target: `joint`, `tendon`, `site`. `dyntype`, `gaintype`, `biastype`이 기본값이 아닌
  `general` 액추에이터는 spec 17.2를 언급하는 경고를 낸다 — 그 매핑은 백엔드의 소관이다.
  이 네 가지 외의 액추에이터 요소 타입은 경고와 함께 건너뛴다.
- `<sensor>`: `jointpos`, `jointvel`, `actuatorfrc`, `framepos`, `framequat`(body /
  xbody / site / geom / camera에 대한 `objtype` + `objname`), `accelerometer`, `gyro`,
  `force`, `torque`, `touch`, `rangefinder`, `camprojection`. 각각 `noise`와 `cutoff`를
  갖는다.
- `<tendon>`: `<joint joint coef>` 자식을 갖는 `fixed`, `<site site>` 자식을 갖는
  `spatial`, 그리고 `range` / `limited`, `stiffness`, `damping`.
- `<asset>`: `mesh`, `texture`, `material`, `hfield`는 `AssetRef`가 된다 — (`meshdir` /
  `texturedir`가 접두된) 경로와 그 경로 문자열의 해시. 파일은 열지 않는다. 이름 없는
  `mesh`는 파일 stem을 취한다. `<geom type="mesh" mesh="...">`와 `material="..."`는
  asset 이름 테이블을 통해 해석된다.
- 모든 이름 참조는 `lookup`을 통해 해석되며, 해석되지 않는 이름은 참조한 요소의 라인과
  함께 `MjcfError::UnknownRef`로 보고된다. 이름 없는 actuator나 sensor는
  `<element>_<target name>`으로 명명되므로, id는 요소 순서와 무관하게 유지된다.
- `<mujoco>` 내부의 파싱 순서는 문서상의 순서와 무관하게 고정되어 있다(`compiler`,
  `option`, `asset`, `default`, `worldbody`, `tendon`, `actuator`, `sensor`), 각 섹션이
  이전 섹션에서 정의된 이름을 해석하기 때문이다.

## acceptance (수용 기준)

- `actuated.xml`: 올바른 종류·게인·gear·limit을 가진 4개의 액추에이터; `general`
  액추에이터는 이름으로 tendon을 target한다; fixed tendon은 joint 계수 순서를 유지하고
  spatial tendon은 site 순서를 유지한다; 올바른 종류와 target을 가진 11개의 센서; 이름
  없는 `jointpos`는 `jointpos_hinge1`로 명명된다; `fovy`는 라디안으로 저장된다.
- `assets.xml`: 5개의 `AssetRef`, 적용된 `meshdir` / `texturedir` 접두, 파일 stem으로
  명명된 이름 없는 mesh, asset id로 해석된 mesh geom과 material, `visual_only`로 표시된
  `contype=0 conaffinity=0` geom.
- 존재하지 않는 joint를 지정한 액추에이터는 올바른 라인과 함께 `UnknownRef`로 실패한다.
- `<equality>` / `<keyframe>`, 그리고 매핑되지 않은 actuator나 sensor 요소는 `warnings`에
  나타난다.

## forbidden (금지)

`context` 밖의 모든 파일. `crates/es-ir/**`. 참조된 asset 파일을 열거나 해싱하는 것(P31 /
P35). 액추에이터 dynamics, noise, transduction을 모델링하는 것 — spec 18.2 / spec 18.3의
리얼리즘은 백엔드와 observation 파이프라인의 소관이다; 이 패킷은 선언된 파라미터만
기록한다. trait 추가(`INV-17`). `HashMap` / `HashSet`(spec 3.4).
