# P09 — Slang mirror of `approx` + coefficient equality

Spec: §3.2 ("Rust와 Slang이 계수·연산 순서를 공유한다"), §3.4, §2.2 (Slang → SPIR-V).

## context

```
crates/es-math/slang/approx.slang
crates/es-math/src/approx/slang_mirror.rs
docs/packets/M0/P09.md
```

## spec

`slang/approx.slang` is a line-for-line mirror of `src/approx/`: the same range reduction, the
same Horner expressions in the same order, and the **same constant names bound to the same
decimal literals**.

- Every constant is declared as `static const float NAME = <literal>;` (Slang) against
  `pub const NAME: f32 = <literal>;` (Rust). Names and literal text must match exactly.
- `slang_mirror.rs` holds only the test: it parses both files, extracts `(NAME, literal)`
  pairs, and asserts the two sets are identical byte-for-byte (same names, same order, same
  literal text).
- Shaders must carry `NoContraction` on these expressions when compiled (§3.4 step 3); that
  is the compile pipeline's job (M2), noted here as the mirror's precondition.

## oracle

```
cargo test -p es-math slang_mirror
```

## acceptance

- The test fails if a coefficient is added, removed, renamed, reordered, or reformatted on
  one side only.
- `slang/approx.slang` compiles under `slangc` — **Target / Status: unverified**: `slangc` is
  not available on the CI host yet, and is wired up with the shader build cache in M2.
- Bit-identical results between the Rust and the GPU path — **Target / Status: unverified**:
  it requires a Vulkan device with the §3.4 execution modes and is M2 acceptance, not P09's.

## forbidden

- No Slang build step, no `slangc` invocation, no SPIR-V artifacts in this packet.
- No change to the coefficient values themselves (that is P08's oracle).
- Do not add a shader crate, a build script, or a `build.rs`.
