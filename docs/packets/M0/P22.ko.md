# P22 — Learning IR 코어 + `PolicyHandle` 계약

Spec: spec 8 (전체), Appendix B.3, spec 5.1–5.3, `INV-16`. 리뷰 클래스 C.

## context (범위)

```
crates/es-ir/src/learning.rs
docs/packets/M0/P22.md
```

## spec (사양)

- spec 8.3 노드 집합을 포괄하는 `LearningNode`: `VisionEncoder`, `StateEncoder`,
  `LanguageEncoder`, `Fusion`, `TemporalEncoder`(spec 7.5 시간 모델의 레이어 3),
  `PolicyHead`(`Regression` | `Diffusion` | `FlowMatching` | `Discrete` | `Energy`),
  `PolicyBundle`(VLA 전체를 불투명하게 참조 — π₀는 분해하지 않는다), `ActionChunker`,
  `Normalizer`(spec 8.3의 `ActionUnnormalizer`는 `direction = Inverse`이다). 파라미터는 타입이
  지정된 필드이다; 가중치는 항상 참조이며 인라인 텐서가 아니다. `impl IrNode`.
- `LearningGraph { schema_version, inputs: Vec<TensorPort>, nodes: Graph<LearningNode>,
  outputs, policy }`와 `PolicyHandle { architecture, base_model, weights, contract }`는
  Appendix B.3 그대로이다. `PolicyContract`는 spec 8.4의 모든 필드를 갖는다.
- spec 8.5의 실행 모드(`ActionExecutionMode`)와 spec 8.6의 청크 전이 데이터
  (`ChunkBlendPolicy`, `ActionChunker::buffer_chunks`)는 데이터로서만 존재한다 — 런타임은 없다.
  `ActionSpec` / `ActionSpace` / `ActionLimits`는 Task IR과 Safety Plane에 남는다.
- `WeightsRef = Safetensors | Onnx | SpirV`, 각각 blake3 다이제스트를 갖는다. `INV-16`: pickle
  변형이 존재하지 않으므로 pickle 경로는 표현할 수 없다.
- `validate()` — `Graph`를 통한 선언 포트와 비순환성, 노드 종류별 입력 수, 경계/계약 일치,
  모든 그래프 입력에 대한 `PortType::check_policy_input`, `execute_chunk ≤ horizon`, 계약
  대 헤드 `action_dim`/`horizon`, `observation_window` 대 temporal 노드, spec 8.4의 지연
  예산(`LRN-052`)을 검사한다.
- `learning_hash()`(아키텍처만, 가중치 독립)와 spec 5.3에 따른
  `policy_hash() = H(weights, learning_hash, base_model)`.

새 코드는 `learning.rs`에 `// TODO(P27-merge)`가 붙은 `pub const`로 존재한다: `LRN-001`
(스키마 불일치), `LRN-002`(입력 수), `LRN-010`(경계), `LRN-011`(계약 입력),
`LRN-020`(`K > H`), `LRN-021`(계약 대 헤드/청커), `LRN-022`(observation window),
`LRN-023`(0 이하의 필드), `LRN-030`(normalizer 방향). `LRN-052`와 `TYPE-011`은
`codes.rs`에서 온다.

`testing::arbitrary_learning_graph()`는 `feature = "testing"`이 아니라
`#[cfg(test)]`이다: `es-ir`는 그런 feature를 선언하지 않으며 `Cargo.toml`은 이 패킷의
범위 밖이다.

## acceptance (수용 기준)

- ACT 형태의 fixture(image + state encoder → fusion → transformer temporal → `Regression`
  head → chunker)는 진단 없이 검증을 통과한다.
- 원시 `Unit::Length` 그래프 입력은 `TYPE-011`로 거부된다.
- `execute_chunk > horizon`은 `LRN-020`으로 거부된다; 10 Hz 루프에서 369.8 ms 정책은
  `LRN-052`이다.
- `learning_hash`는 모든 `NodeId` 재라벨링에 불변이며, 차원이 바뀌면 값이 변한다.
- 가중치 다이제스트나 base model을 바꾸면 `policy_hash`는 변하고 `learning_hash`는
  그대로이다.
- serde 라운드트립은 `arbitrary_learning_graph()`에서도 동등성을 보존한다.
