## spec

- `ObservationNode` covering the spec 7.3 node set: `ImageInput` / `StateInput` /
  `LanguageInput`; `Resize` / `Crop` / `Pad` / `Undistort` / `Rectify` / `Warp` /
  `CameraProjection`; `ColorTransform` / `ToGray` / `ChannelSelect` / `Normalize` /
  `QuantizeU8` / `Dequantize`; `TemporalWindowNode` / `FrameStack` / `Delta`; `Concat` /
  `Stack` / `Mask` / `MultiViewPack`; `Augment` (the spec 7.3 augmentation family, carrying
  `training_only`). `impl IrNode for ObservationNode`.
- `ObservationIr { schema_version, task_ref, graph, temporal, outputs }`. `task_ref` is the
  `task_hash` this IR binds to (spec 7.4): one Task IR, many Observation IRs.
- `TemporalModel` is the spec 7.5 three-layer split: `History` (layer 1, the system ring
  buffer, owned by `es-core` / `es-sensor` — the IR only declares its depth) and
  `TemporalWindow` (layer 2, learning-input meaning, owned here). Layer 3,
  `TemporalEncoder`, belongs to Learning IR and has no type here.
- `propagate_image_specs` walks the graph in topological order and carries `ImageSpec`
  through it. `Resize` / `Crop` go through `ImageSpec::resized` / `cropped`, never a hand
  rolled intrinsics edit (`INV-14`); `Undistort` / `Rectify` go through `undistorted`.
- `validate` returns ports, `TYPE-014` on a `Concat` of different sensor clocks with no
  `time_align`, `OBS-021` on a colour-space mismatch, `OBS-034` on stale intrinsics,
  `Normalize` output unit, augmentation `training_only`, history depth, output binding.
- `observation_hash` = `canonical_hash(graph)` mixed with the canonical bytes of the
  non-graph fields.

## acceptance

- serde round-trip of an `ObservationIr` is equality-preserving.
- 640×480 (`fx = fy = 600`, `cx = 320`, `cy = 240`) → `Resize(224, 224)` →
  `Crop(16, 16, 192, 192)` propagates to `fx = 210`, `fy = 280`, `cx = 96`, `cy = 96`.
- `Resize` with `rescale_intrinsics = false` yields an `OBS-034` warning from `validate`.
- A `CameraProjection` whose declared intrinsics disagree with the incoming spec is an
  `OBS-034` error.
- A `Concat` of two different `TimeRef::Sensor` inputs with `time_align = None` is
  `TYPE-014`; setting `time_align` clears it.
- `observation_hash` is invariant under a `NodeId` relabelling.

## forbidden

Any file outside `context`. Editing `lib.rs`, `codes.rs`, `graph.rs`, `types.rs`,
`image.rs`, `hash.rs`, `Cargo.toml`, or the other four IR modules (P20, P22, P23, P24).
Neural nets or any Learning IR concept (`TemporalEncoder`, encoders, policy heads).
Pixel work, resampling kernels, or any execution (that is the compiler and `es-render`).
Re-deriving intrinsics by hand instead of calling `ImageSpec::resized` / `cropped`
(`INV-14`). `HashMap` / `HashSet`. Committing.
