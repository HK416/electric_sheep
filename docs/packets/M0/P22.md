## spec

- `LearningNode` covering the spec 8.3 node set: `VisionEncoder`, `StateEncoder`,
  `LanguageEncoder`, `Fusion`, `TemporalEncoder` (layer 3 of the spec 7.5 time model),
  `PolicyHead` (`Regression` | `Diffusion` | `FlowMatching` | `Discrete` | `Energy`),
  `PolicyBundle` (a whole VLA referenced opaquely — π₀ is not decomposed), `ActionChunker`,
  `Normalizer` (spec 8.3's `ActionUnnormalizer` is `direction = Inverse`). Parameters are typed
  fields; weights are always a reference, never an inline tensor. `impl IrNode`.
- `LearningGraph { schema_version, inputs: Vec<TensorPort>, nodes: Graph<LearningNode>,
  outputs, policy }` and `PolicyHandle { architecture, base_model, weights, contract }` exactly
  as Appendix B.3. `PolicyContract` carries every field of spec 8.4.
- The spec 8.5 execution modes (`ActionExecutionMode`) and the spec 8.6 chunk-transition data
  (`ChunkBlendPolicy`, `ActionChunker::buffer_chunks`) as data only — no runtime.
  `ActionSpec` / `ActionSpace` / `ActionLimits` stay in Task IR and the Safety Plane.
- `WeightsRef = Safetensors | Onnx | SpirV`, each with a blake3 digest. `INV-16`: no pickle
  variant exists, so a pickle path cannot be represented.
- `validate()` — declared ports and acyclicity via `Graph`, input arity per node kind, the
  boundary/contract agreement, `PortType::check_policy_input` on every graph input,
  `execute_chunk ≤ horizon`, contract vs head `action_dim`/`horizon`, `observation_window` vs
  the temporal node, and the spec 8.4 latency budget (`LRN-052`).
- `learning_hash()` (architecture only, weight-independent) and
  `policy_hash() = H(weights, learning_hash, base_model)` per spec 5.3.

New codes live in `learning.rs` as `pub const` with `// TODO(P27-merge)`: `LRN-001`
(schema mismatch), `LRN-002` (input arity), `LRN-010` (boundary), `LRN-011` (contract input),
`LRN-020` (`K > H`), `LRN-021` (contract vs head/chunker), `LRN-022` (observation window),
`LRN-023` (non-positive field), `LRN-030` (normalizer direction). `LRN-052` and `TYPE-011`
come from `codes.rs`.

`testing::arbitrary_learning_graph()` is `#[cfg(test)]`, not `feature = "testing"`: `es-ir`
declares no such feature and `Cargo.toml` is out of this packet's scope.

## acceptance

- An ACT-shaped fixture (image + state encoder → fusion → transformer temporal → `Regression`
  head → chunker) validates with no diagnostics.
- A raw `Unit::Length` graph input is rejected with `TYPE-011`.
- `execute_chunk > horizon` is rejected with `LRN-020`; a 369.8 ms policy in a 10 Hz loop is
  `LRN-052`.
- `learning_hash` is invariant under relabelling every `NodeId`, and changes when a dimension
  changes.
- Changing the weights digest or the base model changes `policy_hash` and leaves
  `learning_hash` equal.
- serde round-trip is equality-preserving, including under `arbitrary_learning_graph()`.
