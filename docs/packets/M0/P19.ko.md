# P19 — `ImageSpec` + 변환 규칙 (resize / crop / undistort)

Spec: spec 7.2, spec 3.1, Appendix B.2, `INV-14`, spec 28.2 Wave 3. 검토
등급 C.
설계 노트(선행 작성): `docs/design/image-spec.md`.

## context (범위)

```
crates/es-ir/src/image.rs
crates/es-ir/src/lib.rs
docs/design/image-spec.md
docs/packets/M0/P19.md
```

## spec (사양)

- spec 7.2의 모든 필드를 가진 `ImageSpec`: `width`, `height`, `channels`,
  `dtype`, `color_space`, `camera_model`, `intrinsics`,
  `extrinsics`(`es_math::conventions::Pose`, `T_body_camera`),
  `distortion`, `shutter`, `exposure`, `rate_hz`, `depth_scale`.
- `scaled(sx, sy)`를 가진 `Intrinsics { fx, fy, cx, cy, skew }`.
- Appendix B.2 그대로의 `resized(w, h, rescale)`, `cropped(rect, rescale)`,
  `undistorted(new_intr)`.
- `intrinsics_consistent_with(&other)` — `OBS-034` 이면에 있는 비교다.
  진단을 실제로 내는 것은 호출자(컴파일러)의 몫이며, 이 크레이트는
  술어(predicate)와 코드만 제공한다.

## oracle (오라클)

```
cargo test -p es-ir --lib -- image::
```

## acceptance (수용 기준)

- 640×480 spec에 `resized(320, 240, true)`를 적용하면 `fx, fy, cx, cy`가
  절반이 된다.
- `cropped(Rect { x: 80, y: 60, .. }, true)`는 `cx`를 −80, `cy`를 −60만큼
  이동시키고 `fx, fy`는 그대로 둔다.
- `rescale = false`는 내부 파라미터를 비트 단위로 그대로 두며, 그 결과는
  원본과 `intrinsics_consistent_with` 관계가 **아니다**(이것이 `OBS-034`가
  보고하는 것이다).
- `undistorted`는 `distortion`을 `None`으로 지우고 새로운 내부 파라미터를
  설치한다.
- `ImageSpec`의 serde 왕복은 동등성을 보존한다.

## forbidden (금지)

`context` 밖의 어떤 파일도 안 된다. 리샘플링이나 그 어떤 픽셀 작업도 안
된다(그것은 `es-render` / 컴파일러의 몫이다). Observation IR 노드
스키마(P21) 금지. `OBS-021` / `OBS-034`를 발생시키는 것(P26 / 컴파일러)
금지. 기하 변경 시 내부 파라미터 변환을 건너뛰는 것(`INV-14`) 금지.
`rescale`의 기본값을 `false`로 두는 것 금지.
