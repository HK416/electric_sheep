# P40 — Telemetry protocol skeleton

Spec: spec 23 (editor is a client of a running process; backend-neutral protocol), spec 25.1
(security: token auth, QUIC TLS, localhost default), spec 25.3 (versioning: handshake
negotiation, N-1 support), spec 12.4 (the 9 performance metrics), spec 9.6 (embedded runtime
telemetry ring buffer), spec 13.1 (learning loop events).

## spec

- `protocol.rs`: `PROTOCOL_VERSION`; `Hello` / `HelloAck` handshake structs; `negotiate(client,
  server) -> Option<u32>` (highest common version; spec 25.3 requires a server to offer its
  current version and the one before it — `negotiate` itself is generic over whatever list the
  caller passes as `server`); `Message` enum (`Hello`, `HelloAck`, `Subscribe`, `Frame`, `Ping`,
  `Pong`, `Bye`); `Frame { tick: PhysTick, wall_ns, stream: StreamId, payload: Payload }`;
  `Payload` (`Scalar`, `Scalars`, `Tensor`, `Image`, `Event`, `Metrics`); `PerfMetrics` with the
  spec 12.4 metric set as named `Option<f64>` fields (the `p50 / p95 end_to_end_latency` row
  becomes two fields), never a single `step/s` figure.
- Encoding: length-prefixed (`codec` byte + `u32` LE length + body), `serde_json` body,
  `Codec` enum so a binary codec is an additive variant later. `encode`/`encode_with`,
  `decode`/`decode_with_max`. Reject bodies over a configurable max (`DEFAULT_MAX_FRAME_BYTES`
  = 64 MiB) and unknown codec/wire-version tags, both before touching the JSON body.
- `ring.rs`: `RingBuffer<T>` — fixed capacity set at construction (`Vec::with_capacity` +
  `resize_with`, the only allocation), overwrite-oldest `push`, `iter_newest` (newest first),
  `drain_since(seq)` (non-destructive — a ring buffer can have more than one reader; clamps to
  the oldest sequence still held), `dropped()` counter.
- `lib.rs`: doc comment giving the JSON frame shape a thin Python adapter (spec 23.1: LeRobot /
  Isaac Lab / Newton) would emit — only `stream`, `tick`, `payload` required, nothing
  ES-specific.
- No network dependency (no zenoh/quinn/tokio): this packet is schema plus an in-memory ring
  buffer. Transport is `es-transport` (layer 11).

## acceptance

- `negotiate` returns the highest shared version for overlapping lists, the client's version
  when it equals the server's N-1, and `None` when the lists are disjoint.
- Every `Message` variant round-trips through `encode`/`decode` byte-for-byte equal, and
  `decode` reports exactly the number of bytes it consumed.
- `decode_with_max` rejects a body over the max without invoking `serde_json`; an unknown codec
  byte is rejected before the length is even trusted; a truncated buffer is `Incomplete`, not a
  panic.
- `PerfMetrics` serializes with every spec 12.4 metric name present and round-trips; an unset
  metric deserializes back to `None`, never `0.0`; no field is named `step/s` or similar.
- `RingBuffer`: pushing past capacity overwrites the oldest entry and increments `dropped()`;
  `iter_newest` yields newest-first; `drain_since` clamps a stale sequence to what is still
  held and returns nothing for a sequence beyond `next_seq`.
- `push` performs no heap allocation after `with_capacity`, checked via
  `es_core::alloc_count::assert_no_alloc` (this crate's `[dev-dependencies]` turns on
  `es-core`'s `alloc-count` feature so the counting allocator is actually installed for this
  crate's test binary; the test still passes, vacuously, if that ever stops being true, rather
  than failing on an environment it can't observe).

## forbidden

Any file outside `context`. Root `Cargo.toml`. A transport layer (sockets, QUIC, TLS — spec
25.1, `es-transport`, layer 11). A binary codec (the `Codec` enum only makes room for one).
`crates/es-assets/**` (owned by another packet in flight). `HashMap` (determinism, spec 3.4 —
this crate uses `BTreeMap` only). New single-implementation traits beyond the seven extension
points (INV-17). Committing.
