# P21 — Observation IR 코어 + 노드 스키마

Spec: spec 7 (전체), spec 5.1, spec 5.4, `INV-14`. 리뷰 클래스 C.
의존: P18(`types`, `diag`, `codes`), P19(`image`), P27(`graph`, `hash`).

## context (범위)

```
crates/es-ir/src/observation.rs
docs/packets/M0/P21.md
```

## spec (사양)

- spec 7.3 노드 집합을 포괄하는 `ObservationNode`: `ImageInput` / `StateInput` /
  `LanguageInput`; `Resize` / `Crop` / `Pad` / `Undistort` / `Rectify` / `Warp` /
  `CameraProjection`; `ColorTransform` / `ToGray` / `ChannelSelect` / `Normalize` /
  `QuantizeU8` / `Dequantize`; `TemporalWindowNode` / `FrameStack` / `Delta`; `Concat` /
  `Stack` / `Mask` / `MultiViewPack`; `Augment`(spec 7.3의 증강 계열, `training_only` 포함).
  `impl IrNode for ObservationNode`.
- `ObservationIr { schema_version, task_ref, graph, temporal, outputs }`. `task_ref`는 이 IR이
  바인딩되는 `task_hash`이다(spec 7.4): 하나의 Task IR에 여러 Observation IR이 대응한다.
- `TemporalModel`은 spec 7.5의 3계층 분할이다: `History`(레이어 1, 시스템 링 버퍼, `es-core` /
  `es-sensor` 소관 — IR은 그 깊이만 선언함)와 `TemporalWindow`(레이어 2, 학습 입력 의미, 여기 소관).
  레이어 3인 `TemporalEncoder`는 Learning IR 소속이며 여기에는 타입이 없다.
- `propagate_image_specs`는 그래프를 위상 순서로 순회하며 `ImageSpec`을 전파한다. `Resize` /
  `Crop`은 `ImageSpec::resized` / `cropped`를 거치며, 수작업 intrinsics 수정은 절대 하지
  않는다(`INV-14`); `Undistort` / `Rectify`는 `undistorted`를 거친다.
- `validate`는 포트를 반환하며, `time_align` 없이 서로 다른 센서 클록의 `Concat`에는
  `TYPE-014`, 색공간 불일치에는 `OBS-021`, intrinsics가 오래된 경우 `OBS-034`,
  `Normalize` 출력 단위, 증강 `training_only`, history 깊이, 출력 바인딩을 검사한다.
- `observation_hash` = `canonical_hash(graph)`와 비-그래프 필드의 정규 바이트를 혼합한 값이다.

## acceptance (수용 기준)

- `ObservationIr`의 serde 라운드트립은 동등성을 보존한다.
- 640×480(`fx = fy = 600`, `cx = 320`, `cy = 240`) → `Resize(224, 224)` →
  `Crop(16, 16, 192, 192)`는 `fx = 210`, `fy = 280`, `cx = 96`, `cy = 96`으로 전파된다.
- `rescale_intrinsics = false`를 사용하는 `Resize`는 `validate`에서 `OBS-034` 경고를 낸다.
- 선언된 intrinsics가 입력 spec과 불일치하는 `CameraProjection`은 `OBS-034` 오류이다.
- `time_align = None`인 두 개의 서로 다른 `TimeRef::Sensor` 입력의 `Concat`은
  `TYPE-014`이다; `time_align`을 설정하면 해소된다.
- `observation_hash`는 `NodeId` 재라벨링에 불변이다.

## forbidden (금지)

`context` 밖의 모든 파일. `lib.rs`, `codes.rs`, `graph.rs`, `types.rs`,
`image.rs`, `hash.rs`, `Cargo.toml`, 그 외 네 개의 IR 모듈(P20, P22, P23, P24) 수정.
신경망이나 Learning IR 개념(`TemporalEncoder`, 인코더, 정책 헤드).
픽셀 처리, 리샘플링 커널, 또는 어떤 실행이든(그것은 컴파일러와 `es-render`의 몫이다).
`ImageSpec::resized` / `cropped`를 호출하는 대신 intrinsics를 수작업으로 재도출하는 것
(`INV-14`). `HashMap` / `HashSet`. 커밋.
