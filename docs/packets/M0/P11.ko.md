Spec: §18.4, §3.4, Appendix B.8 (시그니처), Appendix D `DET-011`.

## spec (사양)

Appendix B.8이 시그니처를 고정한다; 변경하지 않는다:

```rust
pub trait DeterministicAcc<T>: Default + Clone {
    fn add(&mut self, v: T);
    fn merge(&mut self, other: &Self);   // associative + commutative
    fn finish(&self) -> T;
}
pub struct BinnedAcc<const K: usize = 3> { bins: [f64; K], index: Option<i32> }
```

`DeterministicAcc`는 허용된 일곱 확장 지점 중 하나다(INV-17).

bin당 `W = 20`비트의 Binned/RFA 누산이다: 모든 투입값은 전역 지수 격자 위에서
**절단(truncation)**으로 `K`개 조각으로 분할되어 정확히 더해진다; 더 거친
인덱스로의 재조정은 정확한 bin 시프트다. 정확성 논증과 `2^33`항 상한에 대해서는
설계 문서를 참고하라. `finish`는 bin들을 고정된 순서로 합산한다.

`KahanAcc`는 이 패킷에 포함되지 **않으며** 추가되어서도 안 된다: 보정
합산(compensated summation)은 순서에 의존하여 §18.4 불변식을 위반한다.

## acceptance (수용 기준)

- proptest, 무작위 `f64` 벡터(혼합된 크기, 1–256개 원소): `finish()`는 순차
  순서, 임의의 순열, 같은 원소들에 대한 임의의 분할-병합 트리에 대해 **비트
  단위로 동일**하다.
- proptest: `merge`는 교환적이며(`a.merge(b) == b.merge(a)`, 비트 단위)
  결합적이다.
- `BinnedAcc::default().finish() == 0.0`; 지수 범위가 누산기 하나에 들어맞는
  유한한 `x`를 한 번 `add(x)`하면 정확히 `x`를 반환한다.
- 정확도 확인: `2^60` 동적 범위 내의 벡터에 대해 결과는 `f64` 페어와이즈
  합산과 상대오차 `1e-9` 이내로 일치한다.

## forbidden (금지)

- `KahanAcc`, Neumaier, 그 외 어떤 보정 합산 변형도 없다.
- 원자적 부동소수점 누산 없음, `HashMap` 없음, 전역 RNG 없음(proptest 시드만
  허용).
- `BinnedAcc`의 필드 레이아웃이나 `DeterministicAcc`의 메서드 집합을 변경하지
  않는다.
- `scalar.rs`, `approx/`, `conventions.rs`, `simd.rs`는 건드리지 않는다.
