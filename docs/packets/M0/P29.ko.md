# P29 — `TaskNodeFactory` / `LearningNodeFactory` extension point

Spec: spec 6.3 (Task IR 노드 집합), spec 8.3 (Learning IR 노드 집합), spec 14.5 (에디터 / LLM
노드 생성), spec 28.7 gate 10 (built-in 노드 타입 ID는 M1에서 동결), Appendix C.1 rule 38
/ `INV-17` (허용된 extension point 7개). Spec 28.2 Wave 3. Review class B.

## context (범위)

```
crates/es-ir/src/factory.rs
crates/es-ir/tests/factory_*.rs
docs/packets/M0/P29.md
```

## spec (사양)

- `TaskNodeFactory` / `LearningNodeFactory`: `kinds() -> &[&'static str]`, `create(kind,
  params: &toml::Value) -> Result<TaskNode | LearningNode, Diagnostic>`, `schema(kind) ->
  Option<NodeSchema>`. 이들은 `INV-17`이 총 7개까지 허용하는 extension point 중 2개이며,
  이 패킷은 다른 trait을 추가하지 않는다.
- `NodeSchema { kind, inputs: Vec<Port>, outputs: Vec<Port>, params: Vec<ParamSchema> }`,
  `ParamSchema { name, ty: ParamType, required, default }`, `ParamType { Bool, Int, Float,
  String, Enum(Vec<String>), Shape, PortType }` — 데이터 전용이며, 에디터나 LLM 생성기가
  `TaskNode` / `LearningNode`에 링크하지 않고도 노드와 그 파라미터를 나열하기에 충분하다.
- `BuiltinTaskNodes` / `BuiltinLearningNodes`는 spec 6.3 / spec 8.3 노드 집합의 모든 variant에
  대해 `params`를 재태깅하고 이를 노드 enum으로 역직렬화함으로써 두 trait을 구현한다(둘 다
  serde의 기본 externally tagged representation을 derive하므로, kind별 매핑 코드가 필요 없다).
- `BUILTIN_TASK_KINDS` / `BUILTIN_LEARNING_KINDS`: 동결된 kind-ID 테이블(gate 10의 선행
  단계) — 해당 enum에 대해 `IrNode::kind()`가 반환할 수 있는 모든 문자열을, `kind()`의
  match arm이 쓰는 것과 같은 순서로 담는다.
- `TaskNodeRegistry` / `LearningNodeRegistry`: 등록된 factory들을 보관하고, kind를 그것을
  소유하는 factory 하나로 해석하며, kind가 이미 등록된 것과 겹치는 `register()`는
  `Diagnostic`으로 거부한다.

## oracle (오라클)

```
cargo test -p es-ir factory
```

## acceptance (수용 기준)

- `TaskNodeRegistry::with_builtins()` / `LearningNodeRegistry::with_builtins()`는
  `BUILTIN_TASK_KINDS` / `BUILTIN_LEARNING_KINDS`의 모든 kind를 `schema(kind)` 자신의
  기본값으로부터 빌드하며, 빌드된 노드의 `kind()`, `inputs()`, `outputs()`는 schema와 일치한다.
- 알 수 없는 kind에 대한 `create()`는 `Diagnostic`(`FACTORY-001`)을 반환한다; 알 수 없는
  kind에 대한 `schema()`는 `None`을 반환한다.
- 이미 등록된 kind를 factory가 다시 주장하면 `register()`는 `Diagnostic`(`FACTORY-002`)을
  반환하고, 기존 소유자를 그대로 둔다.
- builtin variant에 대해 `IrNode::kind()`가 반환하는 값을 `BUILTIN_TASK_KINDS` /
  `BUILTIN_LEARNING_KINDS`를 갱신하지 않고 바꾸면 schema/create round-trip 테스트가
  실패한다(gate 10 선행 단계: kind 이름 변경이 `*_hash`를 조용히 바꾸기 전에 여기서 잡힌다).

## forbidden (금지)

`context` 밖의 모든 파일. `Cargo.toml`이나 `lib.rs` 수정(`pub mod factory;` 줄은 이미 존재).
`TaskNodeFactory` / `LearningNodeFactory` 외의 trait 추가(`INV-17`). `codes.rs`에 진단 코드를
직접 추가하는 것 — 이 패킷은 `task::TASK_001`과 마찬가지로 자체 `FACTORY-*` 상수를
`// TODO(P27-merge)`로 로컬에 정의한다. 이 모듈 어디에도 `HashMap`을 쓰지 않는다.
