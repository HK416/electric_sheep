## spec

- `import_gltf(bytes: &[u8], base_dir: Option<&Path>) -> Result<GltfImport, GltfError>` reads
  both `.gltf` (JSON with an embedded data-URI buffer, or an external file resolved against
  `base_dir`) and `.glb` (binary container, buffer in the BIN chunk). No file is opened for a
  `.gltf` with only embedded/data-URI buffers; `base_dir` is only needed for an external URI.
- `GltfImport { scene: SceneDesc, meshes: Vec<MeshData>, materials: Vec<MaterialData>,
  warnings: Vec<Warning> }`. `MeshData { id, name, positions, normals, uvs, indices, material }`
  and `MaterialData { id, name, base_color, metallic, roughness, emissive, textures }` carry the
  payload spec 15.1 asks a mesh/material asset to carry; their `id` matches the corresponding
  `AssetRef` in `scene.assets` so a caller can join the two.
- glTF has no joints: every node becomes a static `Body` (`parent` already means "fixed to
  parent" with no joint targeting it); a mesh node becomes one `Geom` per primitive,
  `contype`/`conaffinity` `0` (glTF carries no collision intent, so none is invented).
- Axis conversion (spec 3.1): glTF is right-handed Y-up, spec 3.1 is right-handed Z-up
  X-forward. `AXIS_FIX`, a fixed quaternion, rotates every position and vertex/normal and
  conjugates every orientation (`q' = FIX*q*FIX^-1`); documented in the module docs, including
  why a per-node conversion composes correctly through the hierarchy without a second tree walk.
- Scale: a uniform node scale is baked into that node's mesh vertex positions. A non-uniform
  scale is left unscaled and recorded as a `Warning` (it would need an inverse-transpose
  correction on normals that this importer does not implement) — never silently dropped.
- Stable ids follow the `crate::mjcf` scheme: `scene_id("body", <node path>)` with the path the
  "/"-joined node name chain from a root; a node/mesh the file leaves unnamed is `node_<index>`
  / `mesh_<index>`. Traversal is document order (`Document::nodes()`, index-first); a node
  reachable only as a child is visited when its parent recurses into it.
- A mesh `AssetRef::hash` is `blake3` of the *decoded* vertex/index arrays, not the source
  bytes: the same geometry as a `.gltf` data URI and as a `.glb` binary chunk hashes identically.
- `GltfError` is a `thiserror` enum (parse/validation, a missing BIN chunk, a bad data URI, a
  buffer whose decoded length disagrees with its declared length, an unreadable external file,
  a primitive with no `POSITION`, a node cycle) — malformed input is always a typed error, never
  a panic.

## acceptance

- A two-node hierarchy (`tests/fixtures/gltf/hierarchy.gltf`) round-trips: body poses match the
  hand-computed axis-converted translation/rotation, the unnamed child gets id
  `body/root/node_1`, and its mesh geometry is axis-converted.
- The same document rebuilt as a `.glb` (built in the test from the same JSON + raw bytes)
  produces the same mesh `AssetRef::hash` as the `.gltf` data-URI version.
- A non-uniform node scale (`nonuniform_scale.gltf`) produces exactly one `Warning` mentioning
  "non-uniform" and leaves the mesh positions unscaled (still axis-converted).
- A buffer whose declared `byteLength` disagrees with its decoded byte count
  (`malformed_truncated.gltf`) returns `GltfError::BufferLength`, not a panic.

## forbidden

Any file outside `context`. `crates/es-assets/src/urdf.rs`, `crates/es-assets/src/fuzz.rs`,
`crates/es-assets/tests/urdf_*.rs`, `crates/es-assets/tests/fuzz_*.rs` (neighbouring packets own
them). `crates/es-physics-*/**`. Editing `Cargo.toml` or `lib.rs` — the `gltf` dependency and
`pub mod gltf;` already exist. Golden files under `tests/golden/` (these fixtures are inputs,
not golden outputs). Adding a trait (`INV-17`). `HashMap` / `HashSet` anywhere (spec 3.4).
Rendering or decoding image pixel data — a texture's `AssetRef` is path-identified only, same as
`AssetRef::from_path` elsewhere, until a later packet actually reads image bytes.
