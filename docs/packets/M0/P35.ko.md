# P35 — 임포터 퍼저

사양: spec 25.1 (에셋 파서 퍼징: "USD/MJCF/URDF/glTF/3DGS ply"), spec 1.7 (에이전트 실패
양상 — 타입이 지정된 오류를 반환하는 대신 적대적 입력에 패닉하는 파서). Spec 28.2
Wave 4, `P35 임포터 퍼저`. 검토 등급 A. P32/P33(MJCF)과 P34(URDF)를 기반으로 한다.

## context (범위)

```
crates/es-assets/src/fuzz.rs
crates/es-assets/tests/fuzz_importers.rs
docs/packets/M0/P35.md
```

## spec (사양)

- `pub fn mutate(xml: &str, seed: u64) -> String`: 호출마다 시드 기반 변이(mutation)를 하나씩
  적용하며, 요소 삭제, 요소 복제, 숫자 속성을 `NaN`/`inf`/거대한 값/빈 값으로 바꾸기, 필수
  속성 제거, 두 속성 값 교환, 문서 절단, 알 수 없는 요소 삽입 중에서 선택한다. 결정적이다:
  동일한 `(xml, seed)`는 항상 동일한 문자열을 반환하므로, CI 실패는 출력된 시드만으로
  재현된다.
- `pub fn fuzz_importer<T, E>(seed_docs: &[&str], f: impl Fn(&str) -> Result<T, E>, cases:
  u32)`: 모든 시드 문서에 대해 `cases`개의 변이를 `f`에 통과시키며, (`std::panic::catch_unwind`를
  통해) 패닉하지 않는지, 케이스당 고정된 시간 예산을 초과하지 않는지를 확인한다. `f`가 `Err`를
  반환하는 것은 성공이다 — 퍼저의 임무는 크래시를 찾는 것이지, 임포터가 올바르게 거부하는
  입력을 찾는 것이 아니다.
- `proptest` 전략 배관(plumbing)은 사용하지 않는다: `(seed_doc_index, case)`로 키를 만드는
  손수 작성한 xorshift64가 더 적은 장치로 동일한 재현성을 제공하며, 이는 이 패킷에서
  명시적으로 허용된 대안이다.
- `tests/fuzz_importers.rs`는 `tests/fixtures/mjcf/*.xml`의 모든 픽스처(`es_assets::parse_mjcf`
  경유)와 `tests/fixtures/urdf/*.urdf`의 모든 픽스처(`es_assets::urdf::parse_urdf` 경유)에
  대해 `fuzz_importer`를 각각 약 256케이스씩 실행한다.
- 개발 중 발견된 패닉은 퍼저가 아니라 임포터의 버그이다: 타입이 지정된 `Result` 오류로
  수정한다. `src/mjcf/**` 내부 수정은 이미 완료된(진행 중이 아닌) P32/P33 코드에 대한
  최소한의 표적 수정으로서만 이 패킷의 범위에 포함되며, 패킷 완료 보고서에 반드시 명시해야
  한다.

## acceptance (수용 기준)

- `mutate`는 결정적이며(동일 시드, 동일 출력), 여러 시드에 걸쳐 실행했을 때 문서를 최소
  한 번은 실제로 변경한다.
- `fuzz_importer`는 의도적으로 패닉하는 클로저가 주어지면 (패닉 전파를 통해) 테스트를
  실패시키고, `Ok`/`Err`만 반환하는 클로저에 대해서는 통과한다.
- 두 픽스처 스위트 모두 각각 256개의 변이된 케이스를 패닉이나 타임아웃 없이 실행한다.
- 이 패킷 개발 중 실제 MJCF 또는 URDF 임포터에서 발견된 패닉은 퍼즈 코퍼스에서 걸러내는
  것이 아니라 그 원인(source)에서 수정한다.

## forbidden (금지)

`context` 밖의 모든 파일. `crates/es-physics-*/**`, `src/gltf.rs`, `tests/gltf_*.rs`,
`tests/fixtures/gltf/**`(동시 진행 중인 패킷 소관). 위에서 언급한 최소한의 패닉 수정을
넘어서는 `src/urdf.rs` 또는 `src/mjcf/**`의 재작성. 퍼징 크레이트 의존성 추가
(`cargo-fuzz`, `arbitrary`) — 이것은 커버리지 기반 퍼저가 아니라 인프로세스 변이
하네스이다. 트레이트 추가(`INV-17`). `HashMap` / `HashSet`(spec 3.4).
