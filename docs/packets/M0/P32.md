## spec

- `mjcf::parse_str(xml) -> Result<Import, MjcfError>`, `Import { scene: SceneDesc, warnings:
  Vec<Warning> }`. Text in, scene out: no file is opened, so the parser is a pure function of
  its input and its output hash is reproducible.
- `<compiler>`: `angle` (`degree` default / `radian`), `eulerseq`, `coordinate` (`local` only —
  `global` is a typed error, not a guess), `meshdir` / `texturedir` / `assetdir`, `autolimits`,
  `inertiafromgeom` (`true` ignores `<inertial>` with a warning; `auto` / `false` use it).
- `<option>`: `timestep`, `gravity`, `integrator`, `cone`, `jacobian`, `solver`, `iterations`,
  `impratio`.
- `<default>`: nested classes with an implicit `main` root, `class=` on an element and
  `childclass=` inherited down the body tree. Merge order is root class first, then each
  derived class, then the element's own attributes.
- `<worldbody>` recursion: `<body>`, `<geom>` (including `fromto`), `<joint>`, `<freejoint>`,
  `<site>`, `<inertial>` (`diaginertia` / `fullinertia`), `<camera>`. The `<worldbody>` itself
  becomes the body `world`, so world-level geoms and cameras have an owner.
- Orientation attributes, in MuJoCo's resolution order: `quat` (wxyz in the file, xyzw and
  `w >= 0` in the scene), `axisangle`, `xyaxes` (Gram-Schmidt), `zaxis`, `euler` (per
  `eulerseq`, lowercase intrinsic / uppercase extrinsic).
- Angles are converted to radians exactly where MJCF means an angle: `euler`, `axisangle`,
  hinge and ball `range` and `springref`. A slide range is a length and is left alone; `fovy`
  is degrees in MJCF regardless of `<compiler angle>`.
- `MjcfError` (thiserror) carries the line from `roxmltree` in every variant: `Xml`, `NotMjcf`,
  `Include`, `Unsupported`, `BadAttr`, `MissingAttr`, `UnknownRef`, `UnknownClass`,
  `BadEulerSeq`. `<include>` is `MjcfError::Include` — "not supported yet" (M1).
- Unknown elements and unknown / unrepresented attributes become `Warning { line, message }`.
  Nothing is dropped in silence.

## acceptance

- `pendulum.xml`: degrees become radians, `fromto` gives the capsule its half-length and its
  pose, `<inertial>` and `<option>` values land as written, ids match `scene_id`.
- `arm2.xml`: explicit attribute beats `childclass` beats parent class beats `main`; `class=`
  on an element overrides the inherited `childclass`; an unknown class is `UnknownClass`.
- `orientations.xml`: all of `quat` / `euler` / `axisangle` / `xyaxes` agree on the same 90
  degree turn, `zaxis` takes `+Z` onto the named axis, and a negative-`w` `quat` comes back
  canonicalised.
- Property (proptest): any `quat`, `axisangle`, `euler` or `zaxis` input parses to a unit-norm
  quaternion with `w >= 0`.
- Reordering sibling bodies in the source does not change `scene_hash`; changing a position
  does.
- `<include>` is rejected with its line number; `<equality>`, `<keyframe>`, `<light>` and an
  unrepresented attribute each produce a warning.

## forbidden

Any file outside `context`. `crates/es-ir/**`. Reading or hashing a referenced file's contents
(P31 / P34 / P35 own that). Editing the root `Cargo.toml` — `roxmltree` is added to
`crates/es-assets/Cargo.toml` only. Adding an XML dependency beyond `roxmltree`. Any physics
computation, including deriving inertia from geoms. `HashMap` / `HashSet` (spec 3.4).
