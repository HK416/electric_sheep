## spec

- `TaskNode` covers the spec 6.3 node set, IR-D only: sources `GetJointState`, `GetBodyPose`,
  `GetBodyVelocity`, `GetContact`, `GetSensor`, `GetTime`, `GetRandom`, `GetLanguage`;
  transforms `Transform`, `Normalize`, `Clamp`, `Arith`, `MathFn`, `Norm`, `Dot`, `Cross`,
  `Compare`, `Logic`, `Select`, `Concat`, `Slice`, `Reduce`; sinks `ObservationSpec`,
  `ActionSpec`, `Reward`, `Terminate`, `Randomization`, `ResetState`, `Record`.
  IR-C (`Sequence`, `Branch`, `SubTask`, `Repeat`) is M4 and has **no variants** (spec 6.2).
  `Parallel` does not exist.
- `impl IrNode for TaskNode`: stable `kind()` strings equal to the spec node names, declared
  input/output `PortType`s, `params_canonical` writing every parameter.
- `TaskIr { schema_version, scene: SceneRef, graph: TaskGraph, observation_spec, config }`,
  `TaskGraph = Graph<TaskNode>`. `ObservationSpec` is a declaration only (spec 5.1, spec 7.4):
  named channels with an `ObsSource` and a `PortType`, and no preprocessing field of any kind.
  `TaskConfig` holds what no node owns — episode budget, control rate, declared RNG streams,
  determinism mode; reset, randomization and termination are nodes.
- `Expr` (spec 6.5): port refs, constants, arithmetic (incl. min/max), comparison, clamp. No
  transcendental variant — those are `MathFn { approx: true }` (spec 6.6 `DET-010`). `eval` is
  total: a missing port, a division by zero, an inverted clamp or any non-finite result is
  `None`, never a `NaN`.
- `TaskIr::validate` — `Graph::validate_declared_ports`, `topo_order`, the spec 6.6 rules
  (`DET-001` empty stream, `DET-021` undeclared stream, `DET-010` std transcendental,
  `DET-030` unordered `Reduce` in deterministic mode), `TYPE-011` on a dimensioned reward term,
  `TASK-001` on an `ObservationSpec` node/declaration mismatch, `HASH-001` on an unencodable
  parameter. `DET-002` and `DET-020` and "no neural nets" are structural: no such node exists.
- `task_hash` (semantic: `canonical_hash(graph)` + canonical scene / observation spec / config)
  and `task_graph_hash` (authoring: the above plus `NodeId`s).
- `testing::arbitrary_task_ir()` — valid connected small graphs for the B.7 properties (P25).

## acceptance

- serde JSON round-trip of `TaskIr` is equality-preserving.
- `validate()` on the valid fixture is empty.
- A cycle yields `GRAPH-001`; a unit mismatch `TYPE-003`; an unaligned `TimeRef` `TYPE-014`;
  the four determinism fixtures yield `DET-001` / `DET-021` / `DET-010` / `DET-030`; a cleared
  declaration yields `TASK-001`; a `NaN` reward weight yields `HASH-001`.
- `task_hash` is unchanged when every `NodeId` is relabelled and the edge list reversed, and
  `task_graph_hash` is not; `task_hash` changes when a reward weight, the scene hash or the
  observation spec changes.
- proptest: every generated task validates clean and keeps its `task_hash` under relabelling.

preprocessing, UI or layout types (rules 6 and 7). `HashMap`. New extension-point traits
(INV-17).
