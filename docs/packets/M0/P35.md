## spec

- `pub fn mutate(xml: &str, seed: u64) -> String`: one seeded mutation per call, picked from
  delete-an-element, duplicate-an-element, flip-a-numeric-attribute-to-`NaN`/`inf`/huge/empty,
  drop-a-required-attribute, swap-two-attribute-values, truncate-the-document, and
  inject-an-unknown-element. Deterministic: the same `(xml, seed)` always returns the same
  string, so a CI failure reproduces from the printed seed alone.
- `pub fn fuzz_importer<T, E>(seed_docs: &[&str], f: impl Fn(&str) -> Result<T, E>, cases: u32)`:
  runs `cases` mutations of every seed document through `f`, asserting (via
  `std::panic::catch_unwind`) that it never panics and never exceeds a fixed per-case time
  budget. An `Err` from `f` is success — the fuzzer's job is to find crashes, not inputs the
  importer correctly rejects.
- No `proptest` strategy plumbing: a hand-rolled xorshift64 keyed on `(seed_doc_index, case)`
  gives the same reproducibility with less machinery, which is the explicitly allowed
  alternative for this packet.
- `tests/fuzz_importers.rs` runs `fuzz_importer` against every fixture in
  `tests/fixtures/mjcf/*.xml` (via `es_assets::parse_mjcf`) and every fixture in
  `tests/fixtures/urdf/*.urdf` (via `es_assets::urdf::parse_urdf`), ~256 cases each.
- A panic found during development is a bug in the importer, not in the fuzzer: fix it with a
  typed `Result` error. A fix inside `src/mjcf/**` is in scope for this packet only as a
  minimal, targeted correction to code P32/P33 already finished (not mid-flight); it must be
  named in the packet's completion report.

## acceptance

- `mutate` is deterministic (same seed, same output) and, over a run of seeds, actually
  changes the document at least once.
- `fuzz_importer` fails the test (via a propagated panic) when given a deliberately panicking
  closure, and passes for a closure that only ever returns `Ok`/`Err`.
- Both fixture suites run 256 mutated cases each without a panic or a timeout.
- Any panic discovered against the real MJCF or URDF importers during this packet's
  development is fixed at its source, not filtered out of the fuzz corpus.

## forbidden

Any file outside `context`. `crates/es-physics-*/**`, `src/gltf.rs`, `tests/gltf_*.rs`,
`tests/fixtures/gltf/**` (owned by concurrent packets). Rewriting `src/urdf.rs` or
`src/mjcf/**` beyond the minimal panic fix called out above. Adding a fuzzing crate
dependency (`cargo-fuzz`, `arbitrary`) — this is an in-process mutation harness, not a
coverage-guided fuzzer. Adding a trait (`INV-17`). `HashMap` / `HashSet` (spec 3.4).
