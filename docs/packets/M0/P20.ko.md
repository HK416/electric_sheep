# P20 — Task IR 코어 + 노드 스키마

Spec: spec 6 (6.1–6.6), spec 5.1 (IR 경계), spec 7.4 (`ObservationSpec`
연결), Appendix B.7. 검토 등급 C.

## context (범위)

```
crates/es-ir/src/task.rs
docs/packets/M0/P20.md
```

## spec (사양)

- `TaskNode`는 spec 6.3의 노드 집합을 다루며, IR-D에만 해당한다: 소스
  `GetJointState`, `GetBodyPose`, `GetBodyVelocity`, `GetContact`,
  `GetSensor`, `GetTime`, `GetRandom`, `GetLanguage`; 변환 `Transform`,
  `Normalize`, `Clamp`, `Arith`, `MathFn`, `Norm`, `Dot`, `Cross`,
  `Compare`, `Logic`, `Select`, `Concat`, `Slice`, `Reduce`; 싱크
  `ObservationSpec`, `ActionSpec`, `Reward`, `Terminate`, `Randomization`,
  `ResetState`, `Record`. IR-C(`Sequence`, `Branch`, `SubTask`, `Repeat`)는
  M4이며 **variant가 없다**(spec 6.2). `Parallel`은 존재하지 않는다.
- `impl IrNode for TaskNode`: spec의 노드 이름과 동일한 안정적인 `kind()`
  문자열, 선언된 입력/출력 `PortType`, 모든 파라미터를 기록하는
  `params_canonical`.
- `TaskIr { schema_version, scene: SceneRef, graph: TaskGraph,
  observation_spec, config }`, `TaskGraph = Graph<TaskNode>`.
  `ObservationSpec`는 선언일 뿐이다(spec 5.1, spec 7.4): `ObsSource`와
  `PortType`을 가진 이름 붙은 채널이며, 어떤 종류의 전처리 필드도 없다.
  `TaskConfig`는 어떤 노드도 소유하지 않는 것들을 담는다 — 에피소드 예산,
  제어 rate, 선언된 RNG 스트림, 결정성 모드; 리셋, 랜덤화, 종료는 노드다.
- `Expr`(spec 6.5): 포트 참조, 상수, 산술(min/max 포함), 비교, clamp.
  초월함수 variant는 없다 — 그것들은 `MathFn { approx: true }`다(spec 6.6
  `DET-010`). `eval`은 전역(total) 함수다: 누락된 포트, 0으로 나누기,
  뒤집힌 clamp, 유한하지 않은 결과는 어느 것도 `NaN`이 아니라 `None`이
  된다.
- `TaskIr::validate` — `Graph::validate_declared_ports`, `topo_order`,
  spec 6.6 규칙들(`DET-001` 빈 스트림, `DET-021` 미선언 스트림, `DET-010`
  표준 초월함수, `DET-030` 결정성 모드에서 순서 없는 `Reduce`), 차원이 있는
  보상 항에 대한 `TYPE-011`, `ObservationSpec` 노드/선언 불일치에 대한
  `TASK-001`, 인코딩 불가능한 파라미터에 대한 `HASH-001`. `DET-002`와
  `DET-020`, 그리고 "신경망 없음"은 구조적이다: 그런 노드 자체가 존재하지
  않는다.
- `task_hash`(의미론적: `canonical_hash(graph)` + 정규화된 scene /
  observation spec / config)와 `task_graph_hash`(저작용: 위에 `NodeId`를
  더한 것).
- `testing::arbitrary_task_ir()` — B.7 속성(P25)을 위한, 유효하게 연결된
  작은 그래프.

## acceptance (수용 기준)

- `TaskIr`의 serde JSON 왕복은 동등성을 보존한다.
- 유효한 픽스처에 대한 `validate()`는 비어 있다.
- 순환은 `GRAPH-001`을 낳는다; 단위 불일치는 `TYPE-003`을; 정렬되지 않은
  `TimeRef`는 `TYPE-014`를 낳는다; 네 가지 결정성 픽스처는 `DET-001` /
  `DET-021` / `DET-010` / `DET-030`을 낳는다; 지워진 선언은 `TASK-001`을
  낳는다; `NaN` 보상 가중치는 `HASH-001`을 낳는다.
- 모든 `NodeId`가 재라벨링되고 간선 목록이 뒤집혀도 `task_hash`는 변하지
  않지만 `task_graph_hash`는 변한다; 보상 가중치, scene 해시, observation
  spec이 바뀌면 `task_hash`도 변한다.
- proptest: 생성된 모든 task는 깨끗하게 검증되며 재라벨링해도 `task_hash`를
  유지한다.

## forbidden (금지)

`context` 밖의 어떤 파일도 안 된다 — 특히 `lib.rs`, `codes.rs`, `graph.rs`,
`types.rs`, `hash.rs`, `Cargo.toml`과 네 개의 자매 IR 모듈(P21–P24). 이
모듈이 필요로 하지만 사전에 없는 코드는 `TODO(P27-merge)`로 로컬에
선언한다. IR-C 노드(M4) 금지. 표현식 파싱과 서브그래프로의
낮춤(lowering)(M1) 금지. Cross-IR 규칙(P26) 금지. 정규화 패스와 나머지
B.7 속성(P25) 금지. TOML / `.esgraph` 직렬화(P28) 금지. 신경망, observation
전처리, UI나 레이아웃 타입(규칙 6, 7) 금지. `HashMap` 금지. 새로운 확장
지점 트레이트(INV-17) 금지.
