# P32 — MJCF 파서 (`<default>`, `<compiler>`)

Spec: spec 3.1(규약: Z-up, `w >= 0`인 xyzw 쿼터니언, SI 단위), spec 5.3(`scene_hash`), spec
17.2(백엔드 시맨틱 매핑), spec 4.3(MuJoCo 계열 백엔드). Spec 28.2 Wave 4. 리뷰 등급 A.
P30을 기반으로 한다.

## spec (사양)

- `mjcf::parse_str(xml) -> Result<Import, MjcfError>`, `Import { scene: SceneDesc, warnings:
  Vec<Warning> }`. 텍스트를 입력받아 scene을 출력한다: 파일을 열지 않으므로 파서는 입력에
  대한 순수 함수이며 출력 해시는 재현 가능하다.
- `<compiler>`: `angle`(기본값 `degree` / `radian`), `eulerseq`, `coordinate`(`local`만
  지원 — `global`은 추측이 아니라 타입이 있는 오류다), `meshdir` / `texturedir` /
  `assetdir`, `autolimits`, `inertiafromgeom`(`true`면 경고와 함께 `<inertial>`을 무시;
  `auto` / `false`면 사용).
- `<option>`: `timestep`, `gravity`, `integrator`, `cone`, `jacobian`, `solver`,
  `iterations`, `impratio`.
- `<default>`: 암묵적 `main` 루트를 가진 중첩 클래스이며, 요소의 `class=`와 body 트리를
  따라 상속되는 `childclass=`가 있다. 병합 순서는 루트 클래스가 먼저, 그다음 각 파생
  클래스, 마지막으로 요소 자신의 속성이다.
- `<worldbody>` 재귀: `<body>`, `<geom>`(`fromto` 포함), `<joint>`, `<freejoint>`,
  `<site>`, `<inertial>`(`diaginertia` / `fullinertia`), `<camera>`. `<worldbody>` 자신은
  body `world`가 되므로, world 레벨의 geom과 camera에도 소유자가 생긴다.
- Orientation 속성은 MuJoCo의 해석 순서를 따른다: `quat`(파일에서는 wxyz, scene에서는
  `w >= 0`인 xyzw), `axisangle`, `xyaxes`(그람-슈미트), `zaxis`, `euler`(`eulerseq`에
  따라, 소문자는 intrinsic / 대문자는 extrinsic).
- 각도는 MJCF에서 실제로 각도를 의미하는 곳에서만 라디안으로 변환된다: `euler`,
  `axisangle`, hinge와 ball의 `range` 및 `springref`. slide의 range는 길이이므로 그대로
  둔다; `fovy`는 `<compiler angle>`과 무관하게 MJCF에서 항상 도(degree) 단위다.
- `MjcfError`(thiserror)는 모든 variant에서 `roxmltree`가 낸 라인 정보를 담는다: `Xml`,
  `NotMjcf`, `Include`, `Unsupported`, `BadAttr`, `MissingAttr`, `UnknownRef`,
  `UnknownClass`, `BadEulerSeq`. `<include>`는 `MjcfError::Include`다 — "아직 지원하지
  않음"(M1).
- 알 수 없는 요소, 그리고 알 수 없거나 표현되지 않는 속성은 `Warning { line, message }`가
  된다. 아무것도 조용히 버려지지 않는다.

## acceptance (수용 기준)

- `pendulum.xml`: 도(degree)가 라디안이 되고, `fromto`가 capsule의 half-length와 pose를
  결정하며, `<inertial>`과 `<option>` 값은 적힌 그대로 반영되고, id는 `scene_id`와
  일치한다.
- `arm2.xml`: 명시적 속성이 `childclass`를 이기고, `childclass`가 parent class를 이기고,
  parent class가 `main`을 이긴다; 요소의 `class=`는 상속된 `childclass`를 오버라이드한다;
  알 수 없는 class는 `UnknownClass`가 된다.
- `orientations.xml`: `quat` / `euler` / `axisangle` / `xyaxes` 모두 동일한 90도 회전에
  대해 일치하고, `zaxis`는 `+Z`를 지정된 축으로 옮기며, `w`가 음수인 `quat`는 정규화되어
  돌아온다.
- 속성 기반 테스트(proptest): 임의의 `quat`, `axisangle`, `euler`, `zaxis` 입력은
  `w >= 0`인 단위 노름(unit-norm) 쿼터니언으로 파싱된다.
- 소스에서 형제 body의 순서를 바꿔도 `scene_hash`는 변하지 않는다; position을 바꾸면
  변한다.
- `<include>`는 해당 라인 번호와 함께 거부된다; `<equality>`, `<keyframe>`, `<light>`
  그리고 표현되지 않는 속성은 각각 경고를 낸다.

## forbidden (금지)

`context` 밖의 모든 파일. `crates/es-ir/**`. 참조된 파일의 내용을 읽거나 해싱하는 것(P31 /
P34 / P35의 소관). 루트 `Cargo.toml` 수정 — `roxmltree`는 `crates/es-assets/Cargo.toml`에만
추가된다. `roxmltree` 외의 XML 의존성 추가. geom으로부터 관성을 유도하는 것을 포함한 어떤
물리 연산도. `HashMap` / `HashSet`(spec 3.4).
