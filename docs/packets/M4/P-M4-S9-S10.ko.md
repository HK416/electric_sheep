# P-M4-S9-S10 — 쓰기 전에 거부하고, 잘못된 `control_rate_hz`를 거부한다

리뷰 should-fix **S-9**와 **S-10**(`docs/reviews/M4.md`)을 닫는다.

## context (범위)

- `crates/es/src/cmd/import.rs` (`roboverse` 서브커맨드)
- `crates/es-data/src/roboverse.rs`
- `crates/es-data/tests/roboverse.rs` (추가만)
- `crates/es/tests/cli.rs` (추가만)
- `docs/packets/M4/P-M4-S9-S10.md` (이 파일)

## spec (사양)

- §14.4(외부 변환) — `severity: error`인 매핑되지 않은 항목은 *실행을 막는다*. 이미
  `task.toml`, `observation.toml`, `provenance.json`을 써버린 뒤의 거부는, 종료 코드를
  제외하면 성공한 import와 구별할 수 없는 디렉터리를 남긴다. 그리고 파이프라인의 다음
  명령은 그 종료 코드를 보지 못한다.
- §6.3 / §5.3 — `control_rate_hz`는 에피소드 길이를 `Terminate(Timeout)` 임계값으로
  나누고 `TaskConfig`에 들어가므로 `task_hash`에까지 도달한다. `0.0`은 거기에 `+inf`를
  넣는다; `NaN`은 훨씬 나중에야 `CanonWriter`에 의해 불투명한 IR 오류로서만 거부된다.

## oracle (오라클)

```
cargo fmt --check
cargo clippy -p es-data -p es --all-targets -- -D warnings
cargo test -p es-data -p es
```

통과/실패 내용:

- `cargo test -p es --test cli import_roboverse` —
  `import_roboverse_writes_nothing_when_an_unmapped_item_blocks_it`: `unknown_checker`
  픽스처는 1로 종료하고, 그 후 `--out` 디렉터리는 존재하지 않는다
  (`import_usd_refuses_a_referenced_layer_by_prim_path`가 `import usd`에 대해 이미
  하는 것과 같은 단언이다). `import_roboverse_exits_1_on_an_unmapped_checker`는 여전히
  통과한다: 매핑되지 않은 항목들은 거부 전에 출력된다.
- `cargo test -p es-data --test roboverse control_rate` —
  `a_nonpositive_or_nonfinite_control_rate_is_a_convert_error`: JSON 경로를 통한
  `0.0`과 `-30.0`, 메모리 내 구조체를 통한 `NaN`과 `+inf`(`serde_json` 자체가
  non-finite 리터럴을 거부한다), 각각 `ConvertError`가 된다; `30.0`과 값이 없는 경우는
  여전히 변환된다.

## acceptance (수용 기준)

- `roboverse_import`는 매핑되지 않은 항목들을 출력한 직후 `blocked` 술어를 계산하고
  `create_dir_all` 이전에 1을 반환한다; 성공하면 0을 반환한다. 도움말 텍스트는 거부 시
  아무것도 쓰이지 않는다고 명시한다.
- `ConvertError::ControlRate(f32)` — `convert`는 유한하지 않거나 0보다 크지 않은
  `Some(hz)`는 무엇이든 거부한다. `None`은 기존의 기본값-플러스-경고 동작을 유지한다.
- 새 trait 없음(INV-17), `BTreeMap`만 사용, 영어만 사용.

## forbidden (금지)

- 변환 자체(checker 매핑, 카메라 매핑, randomization, provenance)와 unmapped/warning
  분류체계는 — 변경 없음.
- `crates/es-eval`, `crates/es-env`, `crates/es-ir`, `crates/es-usd`, `crates/es-script`,
  `crates/es-gpu`, `crates/es-render`, `crates/es-core`, `python/` — 다른 패킷들의
  소유.
- `tests/fixtures/roboverse/` — 새 케이스들은 테스트 안에서 `reach.json`으로부터
  만들어지므로, 픽스처가 추가되거나 수정되지 않는다.
