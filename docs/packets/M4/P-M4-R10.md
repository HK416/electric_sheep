# P-M4-R10 — stop tracking Python bytecode and the Windows-built `es_native` extension

Commit `ac74fa8` (P-M4-R8) added five build outputs next to its declared scope:
`python/es/__pycache__/{__init__,builder,math,selfcheck}.cpython-312.pyc` and
`python/es/es_native.pyd` (3.1 MB, a Windows x86_64 pyo3 build of `crates/es-py`). None of them
is in P-M4-R8's `context`, nothing reads them from git, and all of them are per-machine outputs.
`es_native.pyd` does not load on Linux — the primary platform of §26.1 — where
`maturin develop` writes `es_native.abi3.so` instead. Any interpreter that imports `es` rewrites
the `.pyc` files, so a clean checkout turns dirty just by running the Python oracles; on the Linux
verification host that showed up as `cargo xtask check-scope` reporting them out of scope.

Spec: §1.2 (a packet's diff stays inside its context), §2.4 (Python stays off the runtime path;
the extension is a per-platform maturin build), §26.1 (Linux x86_64 is the primary platform).

## context

```
.gitignore
python/es/__pycache__/*.pyc
python/es/es_native.pyd
docs/packets/M4/P-M4-R10.md
docs/packets/M4/P-M4-R10.ko.md
```

## spec

- The five files leave the index through `git rm --cached`. Their working copies stay on disk,
  so an existing local venv keeps importing its `es_native`.
- `.gitignore` gains a Python section: `__pycache__/`, `*.py[cod]`, `python/es/es_native*.pyd`
  and `python/es/es_native*.so` — the bytecode cache and both platform outputs of
  `maturin develop --release --features python` (Windows `.pyd`, Linux `.abi3.so`). The native
  patterns are scoped to `es_native`, not every `*.so` / `*.pyd` in the tree.
- No build or test reads these files from the repository. `crates/es-py/tests/python_example.rs`
  already requires `es` to be installed with maturin, and `python/es/README.md` already documents
  that step, so neither changes.

## oracle

```
git ls-files -- '*.pyc' '*.pyo' '*.pyd' '*.so' '**/__pycache__/**'
git check-ignore --no-index python/es/__pycache__/x.cpython-312.pyc python/es/es_native.pyd python/es/es_native.abi3.so
cargo xtask check-scope docs/packets/M4/P-M4-R10.md
cargo xtask ci
```

Before the change the first command lists the five files and the second exits 1.

## acceptance

- The first command prints nothing; the second prints all three paths and exits 0.
- `check-scope` and `cargo xtask ci` pass: no build or test depended on the removed files.
- On the Linux host, after `maturin develop` and a full `cargo test` run that imports `es`,
  `git status --short` is clean without any host-local ignore rule or `PYTHONPYCACHEPREFIX`.

## forbidden

- Deleting the removed files' working copies, or changing `crates/es-py/**` or `python/es/*.py`
  — no behavior change to the extension or the builder.
- Rewriting history to purge the `.pyd` from past commits (a force-push to `main`); it stays in
  `ac74fa8`'s history.
- `.github/workflows/ci.yml` — P-M4-R11's scope.
