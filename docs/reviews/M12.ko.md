- **H-1 `render`가 `es`의 기본 feature여야 하는가?** 기본 빌드에는 렌더러가 없어서,
  Python 도구가 모두 설치돼 있어도 두 큐브 카드는 비활성으로 남는다; 시작 화면은 이제
  다시 빌드하는 방법을 말한다. 기본으로 만들면 모든 `cargo build -p es`가 컴파일하는
  것이 바뀐다.
- **H-2 S2 이전에 `es-editor`를 어떻게 분할할 것인가.** egui 셸 아래 헤드리스
  뷰모델을 위한 크레이트는 계층 13이 필요한데(같은 계층 의존은 금지됨), 즉 §4.2와
  부록 C.8에 대한 변경이 필요하다; 아니면 오너가 선호하는 다른 방식으로 자른다.
- **H-3 Y-V가 어디서 도는가.** 로컬 venv(수 GB 다운로드: CUDA가 딸린 torch, mujoco,
  lerobot) 아니면 서버인데, 서버는 지금 접근 금지다.
- **H-4 수집 번들의 선언된 지연.** Y5b는 카메라 전용 수집 번들에 제어 주기 하나(20 ms)를
  줘서, 두 카드의 시연기가 측정된 그대로 돌게 했다; `import-lerobot`은 학습된 ACT
  정책에 200 ms를 선언한다. M11의 열려 있는 "선언된 소스 지연"과 관련됨.
- **H-5 언어와 글자 크기가 View 메뉴로 옮겨졌다**(Y10), M7/E6의 "항상 보임"을 뒤집으며;
