## Findings

### Should-fix (fixed before this review closed)

- **S-1 `es train` could not run in an authored project.** It named its trainer
  `python/es/train_ppo.py` relative to the working directory, and G9 runs `es` in the project's
  folder; only the dry-run had been tested. Fixed in `d90d183`: the script is found above the
  executable. The backbone fetch is fixed the same way.
- **S-2 The `[rl]` rollout read MJCF only.** A `.esscene` reached `es_native.Rollout` as text it
  parsed as XML. Fixed in `d90d183`: `es train` writes the document as one MJCF with G2's writer,
  and `Env::new` checks the pinned `scene_hash` on it.
- **S-3 Unset free-body coordinates started at zero.** `Env::reset` zeroes `qpos` and the compiler
  emitted only the listed start items.
  - Effect in GV: the box began half in the floor.
  - Effect with "say the task"'s defaults (no start items): every object began at the origin,
    inside the robot.
  - Fixed in `d6072f8`: a constant `ResetState` at the scene's pose for every unset lane, with
    `zero_unset = true` keeping the committed specifications' documents. Design note section 4.7.

### Follow-ups (not fixed; proposed as plan G's R-list)

- **F-1 ② cannot test a checkpoint after the documents change.** A save regenerates the documents
  and moves `task_hash`. "Test the saved steps" then evaluates the raw checkpoint, and `es eval run`
  refuses it (evaluation spec 10.4). "Choose" already repacks (`Chose::Pack`); testing should
  repack the same way. In GV the orchestrator repacked by hand.
- **F-2 ⑤'s attempt tiles are blank for the authored project.** The evaluation wrote `rgb_top` /
  `rgb_side` frames; the tiles show none. The cause has not been checked.
- **F-3 The teacher card's time is the Shadow Hand's ("1 to 1.5 hours").** SO-101 measured 47 min.
  The sentence should come from the recipe (iterations × the measured rate), or say nothing.
- **F-4 Words in ①'s task tab.** The sentences are clipped at the pane's width, and the Korean
  particles read "이(가)", "와(과)". Wrap the sentences and pick the particle from the noun.
- **F-5 Meshes have no scale.** An STL in millimetres comes in 1000× too large (G7). Add a mesh
  `scale` to the document and to `SceneDesc` if MJCF's `scale` maps.
- **F-6 The light panel casts a shadow** in the material look (visible since M16's scenes). It is
  the renderer's; an emitter should not occlude.
- **F-7 A trajectory has no row for the terminal state.** The last row is the state before the
  step that ended the episode. Replays and analysis miss the end; GV's "still" check looked wrong
  until this was understood.
- **F-8 "Still" is instantaneous.** A tumbling box that is momentarily slow on landing counts. IR-D
  has no hold node (design note section 4.1); a hold would need one.
- **F-9 Robot joints that no item sets start at 0, not at `qpos0`.** This differs only for joints
  with a `ref`.
- **F-10 Line budget.** `es-editor-model` is at 9,169 of 10,000. The next ⑤ or ② work in it needs a
  split packet first (the model's results and teacher views are candidates). `es-editor` is at
  8,014 (`ui/author.rs`, `ui/sentence.rs`).
- **F-11 Failures explained by the missing clause** (the owner's approved S4 direction). Not built:
  it needs each clause's truth at an attempt's end, recorded by `es eval run`. ⑤ says only "not
  done in time" for an authored task.

### Nits

- **N-1** GV built its project with `--edit-demo authored` and wrote the cameras and the shaped
  clauses as the sentence editor writes them. A person's own clicks through ① were tested by the
  packets' screenshots, not by GV.
- **N-2** The default reward of a said task is the success bonus alone; "inside a region" has no
  shaping. GV added two distance clauses. A shaped default would help a person who does not know
  to.
